# 빈칸지도 Ch7–10

세포분자생물학 시험2 범위(Ch7~Ch10)를 **목차 순서대로** 빈칸으로 외우는 앱입니다.
결과물은 HTML 파일 하나(`dist/빈칸지도.html`)이고, 서버·인터넷 없이 열립니다.

| 챕터 | 교수님 | 절 | 소절 노드 | 줄 | 빈칸 |
|---|---|---|---|---|---|
| Ch7 Replication, Maintenance, and Rearrangements of Genomic DNA | 이규영 | 7.1–7.3 | 32 | 153 | 259 |
| Ch8 RNA Synthesis and Processing | 김재봉 | 8.1–8.3 | 23 | 144 | 210 |
| Ch9 Transcriptional Regulation and Epigenetics | 김재봉 | 9.1–9.3 | 31 | 158 | 285 |
| Ch10 Protein Synthesis, Processing, and Regulation | 조현주 | 10.1–10.4 | 38 | 218 | 401 |

> 챕터 번호는 교재(Cooper) 기준입니다. 예전 `Ch08_빈칸지도.html`은 교재 Ch8+Ch9가 섞여 있었고, `Ch09_빈칸지도.html`은 지금의 Ch10(단백질 합성)입니다.

## 쓰는 법

1. **목차에서 소절을 고릅니다.** (폰에서는 왼쪽 위 `☰ 목차`) 각 항목의 막대는 맞힌 비율, 빨간 점은 틀린 칸이 있다는 표시입니다.
2. **범위**를 `소절 / 절 / 챕터 / 전체` 중에서 고릅니다.
3. 빈칸에 쓰고 **Enter** → 바로 채점되고 다음 칸으로 넘어갑니다.
   - 초록 = 정답, 노랑 = 철자 오류(정답 표시), 빨강 = 오답(정답 표시)
   - 영어는 대소문자·띄어쓰기·하이픈·그리스 문자(α=alpha 등)를 무시합니다.
4. 다 풀면 **▶ 틀린 것만 다시** → 틀린 칸만 비워지고 그 줄만 남습니다. 전부 초록이 될 때까지 반복합니다.
5. 끝나면 **↻ 틀렸던 칸만 복습**으로 한 번이라도 틀린 칸만 모아 다시 풉니다. 다시 전체를 보려면 `모든 칸 보기`.

그 외 버튼: `채점`, `첫 글자 힌트`, `남은 답 보기`, `틀린 것 복사`(오답 목록을 클립보드로), `처음부터`(현재 챕터만 초기화).

### 표시

- **¥25-2** = 기출에 나온 자리. `25-2`는 2025년 2번 문제입니다. 여러 번 나왔으면 `25-6/20-5`처럼 이어 씁니다. 연도·번호를 알 수 없으면 `¥`만 표시합니다. `16이전-N`은 2016년 이전 기출입니다.
- **⭐** = 교수님이 강조한 부분.
- **↻** (빈칸 모서리) = 이번에 한 번이라도 틀린 칸.

### 저장

답과 기록은 **이 기기의 브라우저**에 챕터별로 저장됩니다(`blankmap_ch07` …). 다른 기기와는 동기화되지 않고, 브라우저 데이터를 지우면 사라집니다. 예전 빈칸지도(`chNNmap_v2`)의 기록은 가져오지 못합니다.

## 폰에서 쓰기

화면은 폰 폭(375px)에서 가로 스크롤 없이 확인했습니다. 파일을 폰으로 옮기는 방법(AirDrop, iCloud Drive 등)에 따라 브라우저가 로컬 파일의 저장 기능을 막을 수 있습니다. 이 경우 앱은 열리지만 **새로고침하면 기록이 사라질 수 있습니다.** 기록이 남는지 한 번 확인해 보세요.

## 내용 출처와 한계

- 기존 Ch7·8·9 빈칸지도 내용을 모두 보존하고 목차 구조로 재배치한 뒤, vault 노트(`셀_C7~C10`), 야마, 역대 기출, 강의 PPT와 대조해 빠진 내용을 추가하고 틀린 정답을 고쳤습니다.
- 대조와 추가는 AI가 했고 사람이 전부 검토하지는 않았습니다. **시험 전에 의심되는 줄은 원 자료로 확인하세요.**
- 확인된 자료 간 충돌:
  - Apo-B: vault 노트 46 ↔ 야마·강의·기출 **48** (48 사용)
  - translocation 인자: vault 노트 eIF2 ↔ 야마·강의 **eEF2** (eEF2 사용)
  - 5S rRNA 전사 조립 순서: **TFIIIA → TFIIIC → TFIIIB → Pol III** (노트의 "Pol, B, C, A"는 오류로 보고 수정)
- 기출 번호는 예전 총정리 번호(K-1, `#17`, `C9-N`)를 모두 지우고 연도-문항 번호만 남겼습니다.

## 개발자용

```bash
npm install
npm run dev        # 개발 서버
npm run build      # tsc 검사 + dist/빈칸지도.html 생성
npx vitest run     # 파서·채점·저장소 테스트
```

- 기술 스택: Vite · React · TypeScript · vitest · vite-plugin-singlefile
- 설계/계획 문서: `docs/superpowers/specs/`, `docs/superpowers/plans/`

### 구조

```
content/ch07.md … ch10.md   챕터 내용 (마크다운)
src/parse.ts                마크다운 → 목차 트리
src/engine.ts               채점 (norm / judge)
src/store.ts                챕터별 localStorage 상태
src/App.tsx, components/    목차(Toc), 본문(Pane), 툴바, 빈칸 입력
```

### 내용 수정하기 (`content/chNN.md`)

```
## 8.2 Eukaryotic RNA Polymerases        ← 절 (##)
> 절 한 줄 요약(선택)
### 8.2.1 Eukaryotic RNA polymerases     ← 소절 (###, 목차에 나옴)
- Pol [[I|1|pol1]]이 rRNA 전사 {fire:25-6} {star:교수 강조} {src:야마,기출}
#### 8.2.1.a (선택)                       ← 소소절 (####, 본문에만 나옴)
```

- 빈칸은 `[[정답|대체답1|대체답2]]`이고, 첫 항목이 화면에 보이는 정답입니다.
- 줄 끝 태그: `{fire:25-2}` 기출(여러 개면 태그를 여러 번, 번호를 모르면 `{fire:}`), `{star:…}` 교수 강조, `{src:…}` 근거(화면에는 표시되지 않고 파일에만 남음).
- `-`, `.` 같은 기호만으로 된 정답은 채점 때 지워져서 정답이 될 수 없으니 한글·영문 정답으로 쓰세요.
- 파일을 고친 뒤 `npm run build` 하면 `dist/빈칸지도.html`이 다시 만들어집니다.
- 소절의 칸 id는 목차 위치로 정해집니다. 소절 순서나 위치를 바꾸면 그 소절에 저장된 답은 사라집니다.
