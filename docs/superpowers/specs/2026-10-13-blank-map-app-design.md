# 빈칸지도 앱 설계 (Ch7–10, 시험2)

## 목표
Ch7·8·9 기존 빈칸지도 HTML 3개를 재구성하고 Ch10을 새로 작성해, **목차(교재 계층) 중심**의 단일 앱으로 통합한다. 근거 자료: Kyungho's Vault `셀_C7~C10` 노트, 야마(`20_세포분자생물학/2. 야마`, `21_야마_draft`), 역대 기출, 강의 PPT.

## 확정 사항
- 범위: Ch7, 8, 9, 10 (시험2).
- 기존 내용 재구성 + 부족한 내용 추가. 기출 출제 자리는 🔥, 교수 강조는 ⭐.
- 기술: Vite + React + TypeScript, `vite-plugin-singlefile`로 `dist/빈칸지도.html` 단일 파일 산출. 서버 불필요, 오프라인 동작.
- 위치: `1_셀편/빈칸지도_app/`.

## 구조
1. **콘텐츠**: `content/ch07.md … ch10.md`. 제목 계층(`##` 절, `###` 소절)이 목차 트리. 글머리 한 줄 = 빈칸 한 줄. 빈칸 문법 `[[정답|대체답|…]]`(기존과 동일). 줄 끝 태그: `🔥…`, `⭐…`, 출처 `{vault|야마|기출|PPT}`. 챕터 front matter: 제목, 교수, 연결고리 박스.
2. **파서** (`src/parse.ts`): 마크다운 → `Chapter{ id, title, nodes[Section{ id, title, children, lines[Line{ id, parts[text|blank], tags }] }] }`. 칸 ID는 `ch-섹션경로-줄-순번`으로 안정적이게.
3. **엔진** (`src/engine.ts`): 기존 `norm`/`lev`/`judge` 이식(대소문자·띄어쓰기·하이픈·그리스 문자 무시, 철자 허용). 순수 함수, 단위 테스트.
4. **상태** (`src/store.ts`): 챕터별 `{answers, ever, round, mode, active}`를 localStorage에 저장(`blankmap_ch07` …). 기존 `chNNmap_v2` 키에서 가져오기 지원. 접근 예외는 try/catch.
5. **UI**: 좌측 목차 트리(진행률·오답 점·접기), 상단 breadcrumb·이전/다음 소절, 본문 빈칸. 범위 선택: 소절/절/챕터/전체. 기능: Enter 채점·다음 칸 이동, 틀린 것만 다시, ↻ 복습, 힌트, 남은 답 보기, 오답 복사, 처음부터, 다크모드. 폰에서는 목차가 서랍. 
6. **검증**: vitest(파서·채점), 빌드 후 브라우저로 목차 이동·채점·재도전·저장 복원 확인.

## 콘텐츠 작성 원칙
- 기존 DATA의 사실을 보존하되 교재 목차 순서로 재배치.
- vault 노트·야마·기출·PPT와 대조해 빠진 개념·수치·용어 빈칸 추가, 잘못된 정답은 수정.
- Ch10은 `셀_C10` 노트 + 조현주 야마(상/중/하) + `Chapter10_중하_기출_추출본.md` 기반 신규 작성.
- 대체 정답(한/영, 약어)을 넉넉히 넣는다.
