## 7.1 DNA Replication
> ① 복사 — DNA를 어떻게 똑같이 두 벌 만드나 (S기에 genome 전체 복제)
### 7.1.1 DNA Polymerase
- DNA 복제는 <b>반보존적</b>이며 복제는 세포 주기 중 [[S|S기|S phase|synthetic phase]]기에 일어남 (Interphase = G1-S-G2 / 그 뒤 Mitosis) {src:야마,PPT}
- DNA pol은 [[dNTP|deoxyribonucleotide triphosphate|dNTPs]]의 결합을 촉진해 [[phosphodiester|포스포다이에스터]] 결합으로 사슬을 만듦 {src:야마,vault,PPT}
- 새 dNTP는 [[3′-OH|3'oh|3oh|3'-oh|3 oh]]에만 붙임 → 합성 방향 [[5′→3′|5'→3'|5'3'|53|5->3|5'-3']]만 가능 (3′-OH가 없으면 더 못 붙음) {fire:22-5} {src:vault,야마,기출,PPT}
- 시작하려면 [[primer|프라이머]]가 필요함 → RNA primer를 깔아 주는 효소 = [[primase|프라이메이스]] {fire:} {src:vault,야마,기출}
- leading과 lagging 모두 DNA 합성이므로 <b>둘 다</b> [[primer|프라이머]] strand가 필요함 (leading은 1개, lagging은 여러 개) {fire:25-1} {src:야마,기출}
- primer 없이 de novo 시작 가능한 것 = [[RNA pol|rna polymerase|rnapolymerase|rnapol|rna 중합효소]] / 반면 [[reverse transcriptase|rt|역전사효소]]는 primer가 필요함 (원핵 DNA pol도 primer 필요!) {fire:22-2} {src:vault,야마,기출}
- AZT: 3′ 자리가 OH 대신 [[N₃|n3|azide|아자이드]] → 다음 dNTP 못 붙음 = chain termination → 표적 = HIV [[reverse transcriptase|rt|역전사효소]] {src:vault,야마,PPT}
- retrovirus 게놈의 3개 유전자 = gag · [[pol]] · env (pol = 역전사효소 유전자) {src:vault,PPT}
### 7.1.2 Replication Process
> replication fork · leading/lagging · Okazaki fragment · 효소/단백질 총정리
#### 7.1.2.a Replication fork와 두 가닥
- replication fork = 이중나선이 갈라지는 분기점이며 복제는 [[bi-directional|양방향|bidirectional|양방향성]]으로 진행 (origin 하나에서 양쪽으로) {src:vault,야마,기출}
- 연속 합성 = [[leading|leadingstrand]] strand (primer 1개) / 조각 합성 = [[lagging|laggingstrand]] strand → 조각 이름 [[Okazaki fragment|okazaki|okazakifragments]] {fire:21-1} {src:기존,야마,기출}
- lagging이 조각인 이유 = 합성 방향이 fork 진행 방향과 [[반대|opposite|역방향]] → primer를 계속 새로 깔아야 함 {src:기존,야마}
- Okazaki fragment 길이: 포유류 약 [[200|200bp]]bp / 효모 약 [[2kb|2000|2 kb|2,000]] {src:야마,PPT}
- Okazaki fragment는 <b>lagging</b> strand에서 생기며 leading에서 생긴다는 선지는 오답 → 조각들은 [[DNA ligase|ligase|리게이스]]가 이어 줌 {fire:22-2} {src:야마,기출}
#### 7.1.2.b Okazaki fragment 합성과 primer 제거
- Okazaki 합성 ① [[primase|프라이메이스]]가 RNA primer 합성 (primase는 pol과 달리 primer 없이 NTP를 붙일 수 있음, 5′→3′, RNA에는 T 대신 [[U|uracil|우라실]]) {src:야마,PPT,기출}
- Okazaki 합성 ② DNA pol이 RNA 뒤를 이어 DNA 연장 → 이 RNA-DNA 복합체가 [[Okazaki fragment|okazaki|okazakifragments]] {src:야마}
- 조각 완성 3단계 = 연장 → [[primer 제거|primer제거|primerremoval|프라이머제거]] → 잇기 {fire:} {src:기존,야마}
- Current(시험 기준): δ가 멈추지 않고 밀어 올림(strand-displacement) → [[flap|플랩]] → [[FEN1|fen-1|flap endonuclease 1]]이 절단 → [[DNA ligase|ligase|리게이스]]가 nick 봉합 {src:기존,야마,PPT}
- Old(교재): δ가 멈춤 → [[RNase H|rnaseh|rnase-h]]가 RNA 제거(RNA-DNA hybrid의 RNA를 자르는 endonuclease) → gap을 δ가 채움 → ligase {fire:22-2} {src:기존,야마,PPT}
- 원핵(E. coli)은 primer 제거와 gap 채우기 모두 Pol [[I|1|Ⅰ]]이 담당 (5′→3′ exonuclease로 RNA 제거 + DNA 추가) {fire:21-1} {src:야마,기출}
#### 7.1.2.c DNA polymerase 정리
- 핵 pol 분담: leading = Pol [[ε|epsilon|엡실론|e]] / lagging = Pol [[δ|delta|델타|d]] / primase와 복합체 = Pol [[α|alpha|알파|a]] (짧게 합성하고 떠남) {fire:25-4} {src:기존,야마,기출,PPT}
- lagging strand의 <b>priming</b>에 관여하는 pol = Pol [[α|alpha|알파|a]] ( primase/pol α 복합체 → 짧은 DNA 연장 뒤 δ가 이어 길게 합성) {fire:25-5} {src:야마,기출}
- E. coli: leading·lagging 모두 Pol [[III|3|Ⅲ]], primer 부착 = [[primase|프라이메이스]], 제거 = Pol I {fire:22-2} {src:야마,vault}
- 미토콘드리아 DNA = Pol [[γ|gamma|감마|g]] (세균 pol 억제 항생제가 미토콘드리아를 손상시키는 문제의 답) {src:기존,PPT,vault}
- BER 빈칸 하나 채우기 = Pol [[β|beta|베타|b]] (복제 fork에는 관여 안 함) {src:기존,vault}
- translesion pol = [[ζ|zeta|제타]] · [[η|eta|에타]] · ι · κ (low fidelity, DNA에 느슨하게 결합) {src:기존,vault,야마}
- <b>telomerase(TERT)</b>도 DNA pol의 한 종류로서 [[reverse transcriptase|rt|역전사효소]] 활성을 가짐 {fire:22-4} {src:vault,PPT}
#### 7.1.2.d 복제에 관여하는 단백질
- 이중나선 풀기 = [[helicase|헬리케이스]] (복제 fork 앞에서 풂) → 풀린 ssDNA 보호 = [[RPA|replication protein A|ssb]] → 앞쪽 꼬임 해소 = [[topoisomerase|topo|토포이소머레이스]] (끊고·돌리고·잇기) {fire:22-1} {src:기존,야마,기출}
- topoisomerase는 helicase 앞에서 당-인산 결합을 끊었다 붙이는 <b>swivel</b>로 [[supercoiling|super coiling|supercoil|초나선]]을 방지하며, 이중나선을 자르고 잇는 일은 helicase가 아니라 topo의 일 {fire:22-3} {src:야마,기출}
- sliding clamp = [[PCNA]] (<b>homotrimer</b> 반지, pol δ·ε와 결합) → 끼우는 로더 = [[RFC|replication factor c]] / 빼는 언로더 = [[ATAD5|atad5-rlc]]-RLC {fire:25-2} {src:기존,야마,기출,PPT}
- clamp loader RFC는 PCNA 반지를 열어 ssDNA/dsDNA junction의 [[3′-OH|3'oh|3oh|3'-oh]]가 있는 primer 자리에 PCNA를 얹음 (RFC는 단백질 [[5|5개]]개로 구성) {fire:25-3} {src:야마,PPT,기출}
- PCNA 덕분에 떨어지지 않고 길게 합성하는 성질 = [[processivity|프로세시비티]] (PCNA에 실리는 단백질 150개+) {src:기존}
- leading strand에서는 PCNA loading이 [[1|1번|한 번]]번, lagging strand에서는 Okazaki fragment마다 loading/unloading 반복 {src:야마}
### 7.1.3 The Fidelity of Replication
- 오류율 = 10의 [[9|9승|10^9]]승당 1개 미만 → 사람 게놈 한 번 복제에 약 [[3|3개|세개]]개 (3×10⁹ bp, 약 2 m) {src:기존,PPT,야마}
- 맞는 dNTP가 왔을 때만 pol이 꽉 닫힘 = [[conformational change|conformationalchange|구조변화]] → 정확도 약 [[1000|천|1000배|1,000]]배 증가 {src:기존,PPT,야마}
- 틀린 걸 되돌아가 잘라 냄 = [[proofreading|교정]] = [[3′→5′ exonuclease|3'→5'exonuclease|3'5'exonuclease|35exonuclease|3'-5'exonuclease|exonuclease|3'5'exo]] 활성 {src:기존,PPT,야마}
- proofreading 활성이 있는 pol = 진핵 [[δ|delta|델타]] · [[ε|epsilon|엡실론]] / E. coli Pol [[III|3|Ⅲ]] / 반면 Pol α는 proofreading이 [[없다|없음|x|no|없]] {fire:25-1} {src:야마,기출,vault}
- proofreading을 거치면 약 10⁷~10⁸ nucleotide당 mismatch 1개 수준, 이후 남은 오류는 [[mismatch repair|mmr]]이 해결 {src:야마}
- E. coli에서 proofreading은 Pol [[III|3|Ⅲ]]이 모두 해결한다고 봄 (Pol I만으로 가능하다는 선지는 오답) {fire:21-4} {src:야마,기출}
### 7.1.4 Origins and the Initiation of Replication
- 복제는 origin(ori)에서 [[양방향|bi-directional|bidirectional]]으로 시작 / E. coli = 원형 염색체 1개, origin [[1|1개|한개|하나]]개 / 사람 = 선형 염색체 [[46|46개]]개, <b>염색체 하나에 origin 여러 개</b> (origin 수가 46개라는 선지는 오답) {fire:25-1} {src:기존,PPT,기출}
- genome 크기: E. coli 약 [[4.6×10⁶|4.6x10^6|4.6 x 10^6|460만]] bp vs 사람 약 3.2×10⁹ bp → 진핵은 origin이 많아야 빠르게 복제 {src:PPT}
- E. coli 개시: [[initiator protein|initiator|개시단백질]]이 ori에 결합 → DNA를 살짝 풂 → [[helicase|헬리케이스]] 결합 → SSB 결합 + RNA primer 합성 → DNA 합성 {src:vault,야마,PPT}
- 효모 origin 서열 = [[ARS|autonomously replicating sequence]] (플라스미드에 넣으면 스스로 복제하는 서열) → 핵심 [[11|11bp|11개]]염기 서열 = ACS {src:기존,vault,야마,PPT}
- ACS를 알아보는 복합체 = [[ORC|origin recognition complex]] → 여는 helicase = [[MCM]] (켜지는 시기 [[S|s기|s phase]]기) {fire:} {src:기존,야마,기출}
- 사람 ORC는 효모보다 더 [[복잡|다양|complex]]하게 존재하고, 다른 진핵생물의 origin은 chromatin 구조로 결정되는 듯 명확하지 않음 {fire:22-3} {src:야마,PPT}
### 7.1.5 Telomeres and Telomerase
> 선형 염색체의 끝을 지키고 늘리기
#### 7.1.5.a 말단 복제 문제와 telomere
- 선형 DNA 끝은 [[exonuclease|엑소뉴클레이스|exo]] 공격에 취약 (endonuclease = 한가운데를 자름 / exonuclease = 끝에서부터 하나씩) → 원형 E. coli는 끝이 없어 보호됨 {src:vault,야마,PPT}
- 선형 끝이 매번 짧아짐 = [[end-replication problem|endreplicationproblem|end replication problem|말단복제문제]] (마지막 primer 자리를 채울 3′-OH가 없음) {src:기존,야마,PPT}
- telomere의 3′ 단일가닥 overhang은 안쪽 반복서열과 상보 결합해 고리를 만들고, 이 [[T-loop|tloop|t loop]]가 끝을 숨겨 exonuclease 공격을 차단 {src:야마,PPT}
- telomere = [[TTAGGG]] 반복 + 보호 복합체 [[shelterin|셸테린]] + 3′ 끝이 숨는 [[T-loop|tloop|t loop]] {src:기존,vault,야마,PPT}
#### 7.1.5.b Telomerase와 세포 종류별 차이
- telomerase = 자기 [[RNA|rna template]] template(telomere 반복과 상보적) + 역전사효소 [[TERT]] → 3′ 연장 → 반대 가닥은 lagging 방식 {fire:25-7} {src:기존,야마,기출,PPT}
- 연장 순서: ① 3′ overhang에 telomerase의 RNA template가 상보 결합 → ② 역전사로 one repeat unit 연장 → ③ [[primase|프라이메이스]]와 DNA pol이 5′ 가닥을 연장 {fire:21-3} {src:야마,기출}
- telomerase는 <b>RNA</b> template를 가진 역전사효소이며 (DNA template나 RNA polymerase가 아님) 합성하는 쪽은 [[lagging|laggingstrand]]쪽으로 설명됨 {fire:22-4} {src:야마,기출}
- 생식세포(germ cell)에는 TERT가 있어 길이 유지 / 체세포에는 telomerase가 [[없음|없다|x|no|부족]] → 분열마다 짧아짐 {src:vault,야마,PPT}
- 체세포는 → [[replicative senescence|senescence|복제노화|노화]] 또는 cell death / 암세포는 telomerase 활성 회복 {src:기존,야마}
### 7.1.6 Chromatin Replication
- histone octamer = H2A·H2B·H3·H4 각 [[2|2개|두개]]개 → DNA는 음전하, histone은 [[Lys|lysine|라이신|k]]·Arg가 많아 양전하 {src:기존,야마,PPT}
- Lys [[acetylation|아세틸화|acetyl]] → 양전하 소실 → DNA와의 결합력↓ → 풀림 (효소 [[HAT|hats]]) / 다시 감기 = [[HDAC|hdacs|hd]] {src:기존,야마,PPT}
- 복제 후 하나의 dsDNA가 둘이 되므로 nucleosome 밀도 유지에는 [[histone|히스톤]] 단백질이 더 많이 필요 {src:야마}
- 복제 후 nucleosome 밀도를 유지하려면 기존 histone [[recycling|재활용|recycle]] + 새 histone deposition이 필요 (octamer가 열린 뒤 DNA 합성) {src:기존,야마}
## 7.2 DNA Repair
> ② 고치기 — 망가지면 어떻게 고치나: 손상 모양에 따라 방법이 갈림
### 7.2.1 DNA Damage의 종류
- 손상 원인: 활성산소(ROS) → [[SSB|single-strand break|single strand break]] / 이온화 방사선 → [[DSB|double-strand break|double strand break]] / 자외선 → pyrimidine dimer {src:PPT,야마}
- deamination: 하루 세포당 약 [[10⁴|10^4|10000|1만]]번 → C→[[U|uracil|우라실]], A→[[hypoxanthine|히포잔틴]] (G→xanthine이며 'G→hypoxanthine'은 오답) {fire:22-5} {src:기존,PPT,야마,기출}
- C가 deamination되어 생긴 U는 [[A|adenine|아데닌]]와 염기쌍을 이룸 {fire:25-9} {src:야마,기출}
- alkylation: Guanine → O⁶-methylG는 C 대신 [[T|thymine|티민]]과 염기쌍을 이룸 {fire:25-10} {src:기존,vault,야마,기출}
- UV는 인접한 pyrimidine끼리 결합한 [[pyrimidine dimer|thymine dimer|t dimer|tt dimer|티민 이량체|피리미딘 이량체]]를 만듦 (UV가 DSB·SSB를 주로 만든다는 선지는 오답) {fire:25-14} {src:vault,야마,기출}
- 발암물질(예: [[벤조피렌|benzopyrene|benzoapyrene]]) → DNA 염기에 <b>bulky group</b> 부가 / UV 이량체·bulky group은 backbone을 크게 변형시켜 base만 떼어 낼 수 없음 → NER {src:vault,야마}
- XP(Xeroderma Pigmentosum) = [[NER|nucleotide excision repair]] 결함 → 햇빛 극민감·다발성 피부암 (BER 결함이 아님) {fire:25-11} {src:기존,vault,야마,기출}
- 복제 중 mismatch는 proofreading과 conformational change에도 남는 오류 → [[MMR|mismatch repair]] {src:vault,야마}
- 2015 노벨 화학상: Lindahl = [[BER|base excision repair]] / Modrich = [[MMR|mismatch repair]] / Sancar = [[NER|nucleotide excision repair]] {src:PPT}
### 7.2.2 Base Alteration Repair
> 한 가닥 손상 ① — direct reversal과 BER
- O⁶-methylG → [[direct reversal|directreversal|직접복구]] → 효소 [[O⁶-methylguanine methyltransferase|o6-methylguaninemethyltransferase|methylguaninemethyltransferase|methyltransferase|mgmt]] (절단 없이 methyl기를 직접 제거, minor) / 안 고치면 짝이 C 대신 [[T|thymine|티민]] {src:기존,vault,야마}
- direct reversal은 [[포유동물|사람|mammal|mammalian]]에도 존재함 (존재하지 않는다는 선지는 오답) {fire:22-5} {src:야마,기출}
- BER는 alkylation·deamination 같은 염기 손상 및 SSB를 고치는 [[major|주된|주요]] 경로 (direct reversal은 minor)이며 SSB repair와 후반부가 비슷함 {src:야마}
- BER 1단계: [[DNA glycosylase|glycosylase|글리코실레이스]]가 잘못된 염기(예: uracil)를 인식해 염기-당 결합을 끊어 제거 → [[AP site|apsite|ap|apurinic/apyrimidinic site]] {fire:25-8} {src:기존,야마,기출,PPT}
- BER 2단계: [[AP endonuclease|apendonuclease]]가 AP site의 3′ 쪽을 자름 (= SSB 상태). AP site를 <b>만드는</b> 것은 glycosylase이지 AP endonuclease가 아님 {fire:22-5} {src:기존,야마,기출}
- BER 3단계: [[deoxyribosephosphodiesterase|dRPase|deoxyribose phosphodiesterase|deoxyribosephosphodiesterase 활성]]가 5′ 쪽을 끊어 deoxyribose 제거 → Pol [[β|beta|베타|b]] + [[DNA ligase|ligase|리게이스]]가 채움·봉합 {src:기존,vault,야마,PPT}
- BER 중에는 [[SSB|single-strand break]]가 생기며 (DSB가 생긴다는 선지는 오답), primase가 복구하는 것도 아님 {fire:25-8} {src:야마,기출}
### 7.2.3 UV / Bulky Adduct Repair
> 한 가닥 손상 ② — NER은 backbone째 oligonucleotide로 절제
- UV T dimer → [[NER|nucleotide excision repair]] (손상 앞뒤 oligonucleotide를 통째로 절제) {fire:25-14} {src:기존,야마,기출,PPT}
- (심화) photoreactivation = 가시광선 에너지로 cyclobutane 고리를 깨서 dimer를 직접 해소 → [[태반포유류|placental mammals|태반 포유류|사람]]는 이 기전을 못 씀 {fire:22-5} {src:vault,야마,기출}
- (심화) E. coli의 NER = UvrABC [[excinuclease|엑시뉴클레이스|exinuclease]]가 oligonucleotide를 직접 절제 {fire:21-5} {src:야마,기출}
- GG-NER 1~2단계: 손상 인식(backbone 휘어짐) = [[XPC]] → [[XPA]] + RPA가 손상 맞은편에 결합 {src:기존,vault,야마,PPT}
- GG-NER 3단계: TFIIH의 helicase [[XPB]]·[[XPD]]가 이중나선을 풂 {src:기존,vault,야마}
- GG-NER 4~5단계: endonuclease [[XPG]]·[[XPF]](-ERCC1)가 양쪽을 잘라 oligo를 절제 → pol + ligase가 gap 채움 + nick 봉합 {src:기존,vault,야마}
- [[gap|갭]] = 빈 염기 존재 / [[nick|닉]] = 빈 염기 없이 결합만 안 된 상태 {src:야마}
- TC-NER(전사 중 RNA pol이 멈춘 곳)에서는 RNA pol이 손상을 인식하고 [[CSB]](·CSA)를 동원, 이후는 같은 과정 (XPC 자리를 CSB가 대체) {fire:19-6} {src:기존,야마,기출}
- TC-NER는 BER의 한 종류가 아니라 [[NER|nucleotide excision repair]]의 한 종류임 {fire:21-6} {src:야마,기출}
- NER 결손 질병 = [[xeroderma pigmentosum|xp|색소성건피증]] (햇빛 극민감·피부암) {fire:25-11} {src:기존,야마,기출,PPT}
### 7.2.4 Mismatch Repair
> 한 가닥 손상 ③ — 복제 후 남은 mismatch
- 복제 후 남은 mismatch → [[MMR|mismatch repair]]: E. coli [[MutS]]가 mismatch 인식 → MutL → [[MutH]]와 복합체 형성 {src:기존,야마,PPT}
- MutH endonuclease는 아직 [[methylation|메틸화|methyl]]되지 않은 new strand의 [[GATC]] 서열에서 nick을 냄 {fire:22-6} {src:기존,야마,기출}
- 이후 MutL·MutS가 [[exonuclease|엑소뉴클레이스|exo]]와 helicase를 데려와 nick부터 mismatch까지 제거 → pol + ligase {src:야마,vault}
- 새 가닥을 구별하는 표지 = 아직 methylation 안 됨 → MMR은 methylation된 <b>old</b> strand가 아니라 [[new|새|신생|newly synthesized]] strand의 mismatch를 고침 {fire:21-6} {src:기존,야마,기출}
- 포유류에서는 [[MSH|MutS homolog]](MutS homolog)와 [[MLH|MutL homolog]](MutL homolog)가 mismatch에 결합 → mismatch와 nick 사이 DNA 제거 → repair {fire:25-13} {src:야마,vault,기출}
- 포유류에서는 새로 복제된 DNA의 [[single-strand break|nick|SSB|단일가닥 절단]]이 고칠 가닥을 알려 줌 {src:PPT}
- 사람 MSH·MLH 결손 = [[Lynch syndrome|lynch|hnpcc]] (HNPCC, 유전성 비용종성 [[대장암|colorectal cancer|colon cancer]]) {fire:25-13} {src:기존,야마,기출}
### 7.2.5 Translesion DNA Synthesis
> 못 고치고 넘어가기
- lesion을 만나면 high-fidelity pol([[α|alpha]]·δ·ε)은 정지 / low-fidelity pol은 일단 통과 → 이 기전 = [[TLS|translesion synthesis|translesion DNA synthesis]] {fire:25-16} {src:기존,야마,기출}
- low-fidelity pol은 DNA와 [[느슨하게|loose|loosely]] 결합하고 proofreading이 없어 lesion을 통과 가능 (tight 결합 = high fidelity) / 통과 후 손상은 excision repair로 수정 {src:vault,야마}
- 진핵 TLS 스위치 = PCNA [[mono-ubiquitination|monoubiquitination|monoubiquitylation]] (효소 [[RAD6|rad6a|rad6b]]; poly-Ub = 분해 신호와 구분) {src:기존,야마,PPT}
- TLS pol 4개 = ζ · [[η|eta|에타]] · ι · κ → TT 맞은편에 AA를 정확히 넣는 건 [[η|eta|에타]] {src:기존,vault,야마}
- 끝나면 [[deubiquitination|탈유비퀴틴화|deubiquitylation]] (USP1/UAF1) → 원래 정상 pol 복귀 {src:기존,vault,야마}
- E. coli에서는 Pol [[V|5|Ⅴ]]가 손상 부위를 임시 통과한 뒤 Pol III에 넘김 (II·IV도 비슷) / 진핵에도 TLS는 있음 {fire:22-5} {src:야마,기출}
### 7.2.6 Repair of Double-Strand Breaks
> 두 가닥 손상 — NHEJ vs HR
#### 7.2.6.a NHEJ와 HR의 비교
- DSB 복구 시스템 2개 = [[NHEJ|non-homologous end joining]]와 [[HR|homologous recombination]] {fire:25-15} {src:기존,야마,기출}
- NHEJ: 끊어진 말단을 그대로 이어 붙임 → 세포 주기와 [[무관|상관없이|아무 때나|언제나|g1sg2]], 부정확(insertion·deletion) → 지키는 단백질 [[53BP1|53bp-1]] {fire:} {src:기존,야마,기출}
- NHEJ의 부정확함(insertion·deletion)은 V(D)J 접합의 항체 다양성에 이용됨 ([[error-prone|오류유발|error prone]]한 성질 활용) {src:야마}
- HR: [[S/G2|sg2|s g2|s·g2|s,g2]]기에만, 주형 = [[sister chromatid|sisterchromatid|자매염색분체]] → 정확하지만 느려서 NHEJ보다 적게 일어남 → sister chromatid를 이용한 복구 {fire:25-12} {src:기존,야마,기출}
- G1에는 sister chromatid가 없어 resection이 일어나면 엉뚱한 서열과 짝지을 수 있음 → G1은 [[NHEJ]]가 적합 / S·G2는 [[HR]]이 적합 {src:야마,vault}
- HR 진입 결정 = [[BRCA1]]이 resection을 촉진해 HR 유도 vs [[53BP1]]이 resection을 막아 NHEJ 유도 (서로 경쟁·억제) {src:기존,야마,vault}
#### 7.2.6.b HR 단계
- HR ① nuclease가 [[5′|5'|5prime]] 쪽 가닥을 깎아 [[3′|3'|3prime]] 단일가닥 꼬리 생성 = [[resection|절제|nuclease digestion]] → [[RPA]] 코팅 {fire:} {src:기존,야마,vault}
- HR ② [[BRCA2]]가 RPA를 밀어내고 [[RAD51]]을 loading → RAD51-ssDNA filament {fire:25-17} {src:기존,야마,vault,기출}
- HR ③ filament가 sister chromatid의 상동 서열을 찾아 이중나선 사이로 [[strand invasion|invasion|가닥 침투]] → 파고든 가닥의 3′-OH에서 DNA 합성 {src:기존,야마,vault}
- HR ④ second end capture → 양쪽이 연결된 crossed-strand intermediate = [[Holliday junction|hollidayjunction|holliday]] → ⑤ 잘라서 분리·ligation으로 복구 완료 {fire:} {src:기존,야마,vault}
- 왜 3′ 꼬리? 파고든 뒤 합성이 [[3′-OH|3'oh|3oh|3'-oh]]에서 시작하니까 (DNA pol 한계 재소환) {src:기존,야마}
- 핵심 단백질: 원핵 = [[RecA]] / 진핵 = [[RAD51]] (둘 다 ssDNA에 filament를 만들고 가닥 교환 촉매) {src:야마,vault,기출}
#### 7.2.6.c 임상: BRCA와 Synthetic Lethality
- BRCA1: DSB를 [[HR|homologous recombination]] 쪽으로 보내는 단백질 / BRCA2: RPA 덮인 ssDNA에 [[RAD51]]을 올림 → 변이 시 유방암·난소암 위험↑ {fire:25-17} {src:기존,야마,vault,기출}
- [[synthetic lethality|합성치사]]: 두 유전자 중 하나만 없으면 생존하지만 둘 다 없으면 사멸 {src:기존,야마,vault}
- BRCA 결손 암 + [[PARP inhibitor|parp|parpinhibitor|PARP 저해제]] = 표적 항암제 (Gene B = PARP) {src:기존,야마,vault}
- 평소 [[PARP|parp1]]가 SSB를 복구 → PARP 저해 시 SSB가 남아 S기에 fork와 만나 [[DSB|double-strand break]]가 됨 {src:vault,야마}
- 암세포 = BRCA 결함이라 DSB도 못 고침 → 사멸 / 정상세포 = [[HR|homologous recombination]]로 DSB 복구 → 생존 {src:vault,야마}
## 7.3 DNA Rearrangements and Gene Amplification
> ③ 일부러 바꾸기 — 세포가 일부러 DNA를 옮기고·자르고 붙이고·늘리는 경우
### 7.3.1 Chromosomal Rearrangement
- 재조합 구분: homologous = 가닥은 교환하지만 유전자 순서는 안 바뀜 → rearrangement [[아님|x|아니다|no]] / nonhomologous = 서로 다른 서열 사이에서 끊고 교환 {src:기존,야마}
- 염색체 재배열 종류 = deletion · duplication · [[inversion|역위]] · insertion · [[translocation|전좌]] (병적인 case) {src:vault,야마}
- 특정 서열 두 자리에서 끊고 교환 = [[site-specific recombination|sitespecific|sitespecificrecombination]] {fire:} {src:기존,야마,기출}
- 예: λ phage [[att]] × E. coli att, 효소 = [[integrase|인테그레이스]] {src:기존,야마}
- CML은 돌연변이 누적이 아닌 단 한 번의 [[translocation|전좌]]만으로 발생 {src:vault,야마}
- t(9;22) = [[Philadelphia chromosome|philadelphia|필라델피아]] → [[CML|chronic myelogenous leukemia|chronic myeloid leukemia|만성골수성백혈병]] → 융합 유전자 [[bcr-abl|bcrabl|bcr abl]] (tyrosine kinase가 계속 켜짐) {fire:} {src:기존,야마,vault}
- 9번의 [[abl|ABL]] 유전자와 22번의 [[bcr|BCR]] 유전자가 융합 → BCR-ABL kinase가 growth factor 신호 없이 항상 활성 → cell cycle이 계속 돌아 끝없이 증식 {src:vault,야마}
- 치료제 성분명 [[imatinib|이매티닙]] / 상표명 [[Gleevec|글리벡|glivec]] → BCR-ABL의 [[ATP]] 결합 자리를 막는 표적 항암제 {src:기존,야마,vault}
### 7.3.2 Transposition
- [[transposition|transposon|트랜스포지션]] = genetic element가 genome 안에서 위치를 옮기는 DNA rearrangement (효소 [[transposase]]) → 발견 = [[McClintock|mcclintock|맥클린톡|Barbara McClintock]]의 옥수수 (노벨상) {fire:25-18} {src:기존,야마,기출}
- 보라색 색소 유전자에 [[Ds|dissociation]]가 삽입되면 유전자가 망가져 white kernel {src:vault,야마}
- 자율 = [[Ac|activator]] (transposase를 암호화) / transposase가 없어 의존 = [[Ds]] → 점박이 = 발생 중 일부 [[세포|cell]]에서 Ds가 빠짐 {fire:} {src:기존,야마,기출}
- 사람 게놈: exon [[1.5|1.5%]]% / TE 및 TE-like 반복서열 [[44|44%]]% / 활성 TE [[0.05|0.05%]]% 미만 {fire:} {src:기존,야마,기출}
- 남은 TE는 promoter·enhancer로 작용하거나 [[microRNA|mirna]] 서열, [[poly A|polyA|polyA tail signal|poly A tail]] signal을 제공 {src:vault,야마}
### 7.3.3 Site-Specific Recombination
> 면역 다양성의 원천: B cell/T cell 발달 중 DNA 재배열
#### 7.3.3.a 면역계와 Tonegawa 실험
- 체액성 면역: B cell이 항원을 만나 clonal expansion → [[plasma cell|형질세포]](항체 분비) / [[memory B cell|memory b|기억 B 세포]] {src:vault,야마}
- 세포성 면역: [[helper T cell|helper t|th]]는 cytokine으로 B cell·CTL을 도움 / [[CTL|cytotoxic T lymphocyte]]는 감염 세포를 직접 죽임 {src:vault,야마}
- 한 개체는 약 10<sup>11</sup>가지 이상의 서로 다른 항체를 만들 수 있음 → 다양성 = [[site-specific recombination|sitespecific]] + [[somatic hypermutation|shm|체세포과돌연변이]] {fire:25-19} {src:vault,야마,기출}
- 증명 실험 = [[Tonegawa|토네가와]]의 [[Southern blot|southern|서던블롯]] (embryo = 재조합 전 vs plasmacytoma = 재조합 후; 1987 노벨상) {src:기존,vault,야마}
- Tonegawa 결과: embryo 8.6 + 5.6 kb → plasmacytoma [[3.4|3.4kb]] kb 하나 → V와 C가 한 조각으로 모임 {src:기존,vault,야마}
- 3′-half probe(C만 탐지)는 embryo에서 [[8.6|8.6kb]] kb만 → 8.6 = C 조각, 나머지 5.6 = V 조각 {src:vault,야마}
#### 7.3.3.b 항체 구조와 V(D)J
- immunoglobulin = heavy chain 2개 + light chain 2개 ([[disulfide|이황화]] 결합), 각 chain은 N-말단 variable / C-말단 constant region {src:vault,야마}
- light chain: V [[150|150개]]개 · J [[4|4개]]개 → 150×4 = [[600|600가지]]가지 / heavy chain: V 150 · D [[12|12개]]개 · J 4 → 150×12×4 = [[7200|7,200]]가지 → 조합 약 4×10<sup>6</sup> {src:vault,야마}
- [[V(D)J recombination|vdjrecombination|vdj|v(d)j]] = site-specific → 효소 [[RAG1/2|rag|rag1|rag12|rag1,2]]가 [[RS|recombination signal|rss]] 서열 인식 → DSB → [[NHEJ]]식 접합 {fire:} {src:기존,야마,vault}
- heavy chain 순서 = [[D–J|dj|d-j]] 먼저 → V–DJ / 남은 J는 RNA에서 [[splicing|스플라이싱]]으로 제거 {fire:} {src:기존,야마}
- 접합이 error-prone이라 deletion과 [[TdT|terminal deoxynucleotide transferase|terminal deoxynucleotidyl transferase]]의 insertion으로 다양성이 100배 이상 증가 {src:vault,야마}
- T cell receptor: α chain = [[V–J|vj|v-j]] recombination (light chain형) / β chain = V–[[D–J|vdj|v(d)j]] recombination (heavy chain형) {src:vault,야마}
#### 7.3.3.c Class Switch Recombination
- [[class switch recombination|classswitch|classswitching|classswitchrecombination]]: 처음 class = [[IgM]], 재조합은 [[S|switch|s region]] region끼리, 각 C region의 upstream에 위치 {fire:} {src:기존,야마,vault}
- class switch는 heavy chain의 [[constant|c]] region을 바꾸는 것이므로 variable region·다양성은 [[그대로|같다|안바뀐다|변화없음|same]] → 항체 다양성 기여 2가지 답은 V(D)J와 SHM, class switch 아님 {fire:25-19} {src:기존,야마,기출}
- Sμ와 다른 S region 사이에서 재조합 → 사이 DNA가 고리로 떨어져 나가므로 class switch는 [[한 방향|일방향|irreversible]]으로만 일어남 {src:vault,야마}
- IgG = 혈청 Ig의 약 [[80|80%]]% · IgA = 점막·침·모유 (2량체) · IgM = 5량체, 보체 활성화 · IgD = basophil·mast cell에 결합 {src:vault,야마}
- 알레르기(과활성) 관련 class = [[IgE|이지이]] (기생충 방어) {fire:25-20} {src:vault,야마,기출}
### 7.3.4 Somatic Hypermutation
- 활성화된 B cell의 rearrangement가 끝난 V region에 point mutation을 일으키는 과정, 자연 돌연변이의 약 [[100만|10^6|1000000|백만|백만배]]배 빈도 {fire:25-19} {src:vault,야마,기출}
- SHM은 DNA 재배열이 아니라 [[point mutation|점돌연변이|점 돌연변이]]이므로 DNA rearrangement에 속하지 않음 (그러나 다양성을 높임) {src:vault,야마}
- 시작 효소 [[AID|activation-induced cytidine deaminase|activationinduceddeaminase]] = activation-induced cytidine deaminase, 반응 [[C→U|cu|c-u|c->u|ctou]] {fire:} {src:기존,vault,야마}
- AID가 V region에 작용 → U를 BER로 제거 → 빈자리를 [[error-prone|오류유발|error prone]] DNA pol이 채움 → [[somatic hypermutation|shm|체세포과돌연변이]] {src:기존,vault,야마}
- AID가 S region에 작용 → 양쪽 가닥 가까운 C를 U로 바꿈 → BER로 제거되며 [[DSB|double-strand break]] 발생 → class switch {src:vault,야마}
### 7.3.5 Gene Amplification
- [[gene amplification|geneamplification|유전자증폭]] = 같은 origin에서 복제를 [[다시|반복|여러번|again]] 시작해 특정 유전자의 copy 수를 늘림 (genome 구조가 바뀌므로 DNA rearrangement의 예) {src:기존,vault,야마}
- 정상 예 = 양서류 알의 [[rRNA|rrna유전자]] 유전자 (초기 발생 때 증폭, 약 100만 copy까지) {src:기존,vault,야마}
- 정상 예 = [[Drosophila|초파리]] 난소 세포의 [[eggshell|알껍질|egg shell]] protein 유전자 증폭 {src:vault,야마}
- 병적 예 = 암세포의 [[oncogene|암유전자|oncogeneamplification]] 증폭 (예: ABL 증폭 → 세포주기 계속 회전) {fire:} {src:기존,vault,야마}
- 유전자 copy 수가 늘어난 만큼 [[발현량|expression|발현]]도 증가 {src:vault,야마}
