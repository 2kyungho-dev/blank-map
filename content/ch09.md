## 9.1 Gene Regulation in E. coli
> lac operon: repressor(negative)와 CAP(positive)가 만나는 2×2 표, 그리고 cis(서열) vs trans(단백질)

### 9.1.1 Lac operon
- lactose = [[galactose|갈락토스]] + [[glucose|글루코스|포도당]]이 [[β(1→4)|beta14|b14|beta(1-4)]] glycosidic bond로 연결된 이당류 / galactose는 C4의 –OH가 위쪽 (glucose와 C4 방향만 다름) {fire:21-3/22-4/23-4/25-5} {src:야마,기출}
- lacZ 산물 = [[β-galactosidase|betagalactosidase|베타갈락토시데이스]] → lactose를 galactose + glucose 두 단당으로 분해 {fire:17-2/19-3/22-4} {src:야마,vault,기출}
- lacY 산물 = [[lactose permease|permease|퍼미에이스]] → lactose를 세포 안으로 transport {fire:17-2/19-3} {src:야마,vault,기출}
- lacA 산물 = [[transacetylase|thiogalactoside transacetylase|트랜스아세틸레이스]] → 독성 [[thiogalactoside|티오갈락토사이드]]를 inactivate (detoxification) {src:야마,vault}
- z, y, a를 하나의 promoter가 한 단위로 전사 = [[operon|오페론]] (이런 성질 = [[polycistronic|폴리시스트로닉]]) / 진핵은 대부분 [[monocistronic|모노시스트로닉]] {src:야마,vault}
- [[operator|o|오퍼레이터]] = promoter 바로 옆, repressor가 결합하는 DNA sequence / i gene = operon 바깥에서 [[repressor|리프레서]]를 encode {fire:20-3} {src:야마,vault,기출}
- 배열 순서: i – p – o – [[z|lacZ]] – [[y|lacY]] – [[a|lacA]] {fire:19-3} {src:야마,vault,기출}
- lactose가 없을 때: repressor가 operator에 결합 → RNA polymerase가 [[promoter|프로모터]]에 결합하지 못함 → 전사 OFF {src:야마,vault}
- lactose가 있을 때: lactose의 이성질체 [[allolactose|알로락토스]]가 repressor에 결합 → repressor [[inactivation|불활성화|inactive|inactivate]] → 전사 ON (올해 PPT 본문은 lactose로 표기, Fig 8.7·기출 답은 allolactose) {fire:22-2/23-2/25-2} {src:야마,vault,기출}
- i gene 산물을 만들지 못하는 mutant는 lactose가 없어도 operon이 [[발현된다|발현|전사된다|expressed|ON]] → i 산물 = 전사를 막는 repressor라는 근거 {src:야마}

### 9.1.2 cis-acting elements and trans-acting factors
- 전사 조절의 central principle: [[regulatory protein|regulatory proteins|조절 단백질]]과 specific [[DNA sequence|DNA 서열|서열]]의 상호작용 {src:야마,PPT}
- cis-acting element(= cis-acting control element)의 실체 = [[DNA sequence|DNA 서열|서열]] → 같은 DNA molecule 위에 linked된 유전자에만 영향 {star:교수 강조 - 자주 묻는다} {src:야마,PPT}
- trans-acting factor의 실체 = [[protein|단백질]] → 세포 안을 돌아다녀 다른 chromosome의 유전자에도 작용 가능 {star:교수 강조 - 자주 묻는다} {src:야마,PPT}
- 판단 기준은 하나: 서열이면 [[cis]], 단백질이면 [[trans]] {src:야마}
- lac operon (negative control)의 cis-acting element = [[operator|오퍼레이터]] / trans-acting element = [[repressor|리프레서]] {fire:20-4/22-3/25-4} {src:야마,vault,기출}
- 원핵 cis 예: operator, promoter(-10, -35) / 진핵 cis 예: promoter, [[enhancer|인핸서]], [[insulator|인슐레이터]], TATA box, GC box {fire:17-3/21-6} {src:야마,vault,기출}
- 진핵 trans 예: activator, repressor, [[CTCF]] / 원핵 trans 예: repressor, [[CAP|catabolite activator protein]] {src:야마,vault}
- 전사를 촉진하는 대표 cis element = [[enhancer|인핸서]] / 방해하는 대표 cis element = [[operator|오퍼레이터]] {fire:16-2} {src:야마,기출}
- 전사를 촉진하는 trans element = transcriptional [[activator|액티베이터]] / 방해하는 trans element = [[repressor|리프레서]] {fire:18-2} {src:야마,기출}
- repressor는 서로 다른 두 DNA molecule의 operator에 모두 결합 가능 → [[trans]] / operator 서열은 자기 아래 같은 DNA의 z·y·a에만 영향 → [[cis]] {src:야마}

### 9.1.3 Positive and negative control
- negative/positive control을 나누는 기준은 DNA 서열이 아니라 [[protein|단백질|조절단백질]] {fire:21-1/23-2/25-2} {star:교수 강조 - DNA가 아니고 단백질} {src:야마,vault,기출}
- negative control: regulatory protein [[repressor|리프레서]]가 전사를 block, 조절인자 = [[allolactose|알로락토스]] {fire:17-1/22-2/23-2/25-2} {src:야마,vault,기출}
- positive control: regulatory protein [[CAP|catabolite activator protein|crp]]이 전사를 activate, 조절인자 = [[cAMP|cyclic amp]] {fire:17-1/21-2/18-1/22-2/25-2} {src:야마,vault,기출}
- glucose가 줄면 [[adenylyl cyclase|아데닐릴 사이클레이스]]가 ATP로부터 cAMP를 만듦 / glucose가 많을 땐 [[α-ketoglutarate|alpha-ketoglutarate|a-ketoglutarate]]가 adenylyl cyclase를 억제 {fire:21-2} {src:야마,vault,기출}
- cAMP가 CAP에 결합 → cAMP-CAP이 promoter [[upstream|상류]]의 CAP binding site에 붙어 RNA polymerase의 promoter 결합을 도움 → 전사 ↑ (catabolite = glucose·lactose 같은 분해 대사물질) {fire:18-1} {src:야마,vault,기출}
- lactose [[없음|absent|-]] / glucose [[있음|present|+]] → repressor는 operator에 결합, CAP은 결합 못 함 → 전사 [[OFF|없음|x|-]] {fire:19-4} {src:야마,기출}
- lactose [[없음|absent|-]] / glucose [[없음|absent|-]] → repressor가 operator에 결합, CAP은 결합 → 전사 [[OFF|없음|x|-]] {fire:19-4} {src:야마,기출}
- lactose [[있음|present|+]] / glucose [[있음|present|+]] → repressor는 떨어지나 CAP 결합 못 함 → 전사 [[거의 없음|OFF|낮음|-]] (glucose를 먼저 사용) {src:야마}
- lactose [[있음|present|+]] / glucose [[없음|absent|-]] → repressor 떨어지고 CAP 결합 → 전사 [[ON|+|최대|많음]] {fire:19-4} {src:야마,기출}
- 효율적 전사 = CAP 결합과 repressor 해리가 동시에 필요: CAP은 [[positive|양성]]하게, repressor는 [[negative|음성]]하게 작용 {src:야마,PPT}
- 사람에서도 혈당이 떨어지면 [[epinephrine|glucagon|에피네프린|글루카곤]] 같은 hormone이 세포 안에 [[cAMP]]를 만들어 glycogen을 분해 (glucose 낮을 때 cAMP ↑는 세균·사람 공통) {src:야마}

## 9.2 Transcription Factors in Eukaryotes
> 실험 4종: gene transfer assay(cis 서열 찾기) · EMSA(in vitro 결합) · ChIP(in vivo 결합) · DNA-affinity chromatography(TF 정제)

### 9.2.1 Regulatory sequences and gene transfer assay
#### 9.2.1.a Gene transfer assay
- 진핵 유전자의 cis-acting regulatory sequence를 찾는 실험 = [[gene transfer assay|gene transfer|transfection assay]], 조절 서열 후보를 [[reporter gene|reporter]] 앞에 붙여 reporter 발현량으로 활성 판정 {fire:19-7/20-7/22-8} {src:야마,vault,기출}
- 1단계: genomic DNA의 regulatory sequence(promoter 부위, 보통 TSS upstream 약 [[2 kb|2kb]])를 plasmid의 [[MCS|multiple cloning site]], 즉 reporter gene의 upstream에 삽입 {fire:21-20} {src:야마,vault,기출}
- 2단계: 이 plasmid를 cultured cell에 [[transfection|형질주입|transfect]] / 3단계: reporter gene의 [[발현|expression|활성]]을 측정 {fire:19-7/20-7} {src:야마,vault,기출}
- reporter gene = 쉽게 검출되는 효소를 encode하며 보통 세포에 없는 유전자 → 대표 = 반딧불이 [[firefly luciferase|luciferase|루시퍼레이스]] (β-galactosidase도 인정) {fire:22-8} {src:야마,vault,기출}
- vector 필수 3요소: [[ORI|origin of replication]] · [[selection marker|drug resistance|항생제 저항성|resistance gene]] · [[MCS|multiple cloning site]] {src:야마}
- 잘라 오는 조각의 3′ 끝: TSS는 [[포함|include]], TLS는 [[제외|exclude|미포함|포함 안 함]] → 3′ primer 위치 = [[TSS와 TLS 사이|between TLS and TSS|between TSS and TLS|TSS TLS 사이]] {fire:21-20} {star:교수 강조 - 문제 형식으로 설명} {src:야마,기출}
- TSS보다 upstream에서 끊으면 [[전사|transcription]]가 시작되지 못하고, TLS를 지나 끊으면 genomic ATG에서 번역이 먼저 시작되어 reporter가 제대로 안 만들어짐 / 둘 사이 구간 = 5′ [[UTR|untranslated region]] {src:야마}
- TSS = transcription [[start|시작]] site (+1) / TLS = translation start site (ATG) {src:야마}

#### 9.2.1.b Promoter의 cis element
- 조각을 조금씩 잘라 내거나(serial deletion) mutation을 넣어 reporter 발현이 뚝 떨어지면 그 자리에 [[positive|활성|양성]] element가 있다는 뜻 {src:야마}
- herpes simplex virus [[thymidine kinase|TK|티미딘 키네이스]] 유전자에서 두 promoter element [[TATA box|TATA]]와 [[GC box|GC]]를 발견 {fire:17-3} {src:야마,vault}
- 위치(TSS +1 기준): GC box [[-100|100]] / CAAT box [[-75|75]] / GC box [[-50|50]] / TATA box -25 {src:야마,vault}
- 서열: GC box = [[GGGCGG]] / TATA box = [[TATAA]] / CAAT box = CCAAT {src:야마}
- cis-acting regulatory sequence는 보통 TSS의 [[upstream|상류|위쪽]]에 있다 {src:야마}

#### 9.2.1.c Enhancer와 DNA looping
- [[enhancer|인핸서]] = TSS에서 멀리 떨어져 promoter 전사를 크게 stimulation하는 cis-acting regulatory sequence / [[SV40]] virus promoter 연구에서 처음 발견 (72-bp repeats) {fire:16-2/17-3} {src:야마,vault,기출}
- enhancer는 TSS와의 [[distance|거리]], [[orientation|방향]], upstream/downstream 위치와 상관없이 작동 {src:야마,vault,기출}
- 작동 원리 = DNA [[looping|loop|루핑]]: 1) enhancer에 gene-specific·tissue-specific TF 결합 {src:야마,vault}
- 2) DNA가 loop를 만들어 enhancer의 TF가 promoter의 [[Mediator|미디에이터]], GTF, RNA polymerase II(preinitiation complex)와 interaction {src:야마,vault}
- 3) promoter에 preinitiation complex가 더 잘·더 자주 형성 → 전사 ↑ / loop는 고리 모양의 [[cohesin|코헤신]]이 안정화 {src:야마,vault}
- immunoglobulin enhancer는 [[B lymphocyte|B cell|B 림프구]]에서만 작동 → cis element와 그 세포의 trans factor가 동시에 있어야 조절 / heavy-chain enhancer는 약 200 bp 안에 최소 [[9|9개]]개의 protein-binding site {src:야마}
- enhancer는 human genomic DNA의 [[10%|10]] 이상을 차지하고, 질병 관련 mutation의 다수가 coding sequence가 아닌 enhancer에 있음 / 한 유전자를 multiple enhancers가 함께 조절 {src:야마}

#### 9.2.1.d Insulator, TAD, CTCF
- enhancer는 거리와 무관하지만 같은 [[TAD|topologically associating domain|topologically associated domain]] 안의 promoter에만 작용 (TAD = 서로 독립된 chromosomal domain) {fire:17-6/18-4/21-13} {src:야마,vault,기출}
- [[insulator|인슐레이터]] = chromosome을 독립된 domain(TAD)으로 나누어 enhancer가 인접 domain의 promoter에 작용 못 하게 하는 DNA sequence → [[cis]]-acting element {fire:22-9} {src:야마,vault,기출}
- insulator에 결합하는 vertebrate의 주된 단백질 = [[CTCF]] → [[trans]]-acting factor / insulator 자리에는 CTCF와 [[cohesin|코헤신]]이 결합 (vault: TFIIIC도 결합) {fire:17-6/18-4/21-13} {src:야마,vault,기출}
- 정리 세트(답 3개): domain = [[TAD]] / cis-acting control element = [[insulator]] / trans-acting control element = [[CTCF]] {fire:17-6/18-4/21-13} {src:야마,기출}
- enhancer의 유전자 특이성을 제한하는 cis-acting element = [[insulator]] {fire:22-9} {src:기출}

### 9.2.2 Transcription factor binding sites
#### 9.2.2.a EMSA (in vitro)
- [[EMSA|electrophoretic mobility shift assay|electrophoretic-mobility shift assay]] = 찾아낸 regulatory sequence에 TF가 결합하는지 [[in vitro|시험관]]에서 확인 / 다른 이름 gel [[retardation|shift|retardation assay|gel shift]] assay {fire:16-3/18-3/19-8/20-8/22-13/23-8/25-9} {src:야마,vault,기출}
- 1) 추정 binding site를 포함한 짧은 DNA fragment(약 20 nt)의 한쪽 끝을 [[radiolabel|방사성 표지|radioactive label|radiolabeled]] {src:야마,vault}
- 2) 이 DNA를 단백질(nuclear extract)과 함께 incubate한 것과 단백질 [[없이|without|없는]] incubate한 것으로 나눔 {src:야마,vault}
- 3) electrophoresis 후 [[autoradiography|오토라디오그래피]]: free DNA는 빨리 내려가고, DNA-protein complex는 이동이 느려 위쪽에 band (= mobility [[shift|시프트]]) {src:야마,vault}
- 추정 TF의 antibody를 함께 넣으면 DNA–단백질–antibody가 더 커져 band가 더 위로 = [[supershift|슈퍼시프트]] / 결합을 방해하면 band가 [[사라짐|없어짐|disappear]] {src:야마,vault}

#### 9.2.2.b Binding site의 성질과 pictogram
- TF binding site는 보통 [[6-10|6~10|6–10]] bp(4~12)의 짧은 DNA sequence이고 [[degenerate|퇴화]] → consensus에서 한두 자리 달라도 결합 {src:야마,vault}
- 알려진 결합 서열의 염기 빈도를 막대로 나타낸 그림 = [[pictogram|logo|sequence logo]] {src:야마,vault}
- AP1 = [[Jun]] family + [[Fos]] family dimer, 핵심 서열 [[TGAC]] {src:야마,vault}
- [[Myc]] = oncogene 산물로 cancer를 유발하는 TF / [[SRF|serum response factor]] = serum의 growth factor에 반응하는 유전자의 [[SRE|serum response element]]에 결합 {src:야마,vault}

#### 9.2.2.c ChIP (in vivo)
- [[ChIP|chromatin immunoprecipitation|chip]] = 세포 안([[in vivo|생체 내]])에서 TF가 genome의 어느 서열에 실제 결합해 있는지 알아내는 실험 {fire:16-3/17-7/18-3/19-9/20-9/21-14/22-14/23-8/25-9} {src:야마,vault,기출}
- 1) [[formaldehyde|포름알데하이드|포름알데히드]]로 처리해 TF와 DNA를 cross-link {src:야마,vault}
- 2) chromatin을 추출해 잘게 fragmentation ([[sonication|초음파|초음파 처리]], 약 200~500 bp) {src:야마,vault}
- 3) 목표 TF에 specific한 [[antibody|항체]]로 immunoprecipitation (antibody가 없으면 Myc 같은 [[tag|태그]]를 붙여 발현시키고 tag antibody 사용) {src:야마,vault}
- 4) [[reverse cross-link|reverse crosslink|cross-link 제거|crosslink 풀기]]로 DNA만 정제 {src:야마,vault}
- 5) 분석: 추정 TFBS에 primer를 짜서 개별 확인 = [[PCR]] / 딸려 온 fragment 전부를 microarray·high-throughput [[sequencing|NGS|시퀀싱]]로 분석 = [[genome-wide analysis|genome wide analysis|genome-wide]] {fire:19-9/20-9/21-14/22-14} {src:야마,vault,기출}
- 정리 세트: in vitro = [[EMSA]] / in vivo = [[ChIP|chromatin immunoprecipitation]] {fire:16-3/18-3/22-13/23-8/25-9} {src:야마,기출}

### 9.2.3 Transcriptional regulatory proteins
#### 9.2.3.a DNA-affinity chromatography
- 처음 분리된 TF 중 하나 = [[Sp1|specificity protein 1]], SV40 promoter의 [[GC box|GC]]에 결합하는 activator (Tjian) {src:야마,vault}
- TF 정제법 = DNA-[[affinity|어피니티]] chromatography: GC box 반복 ds oligonucleotide를 [[agarose|아가로스]] bead에 붙여 column 제작 {src:야마,vault}
- cell extract를 통과시키면 Sp1만 GC box에 high affinity로 결합 → [[high salt|고염|고염 buffer]] buffer로 Sp1을 떼어 내면 purified Sp1 {src:야마,vault}
- TF는 세포 안에 [[소량|적은 양|극소량]]만 있어 일반적 방법으로 분리가 어려워 이 정제법이 의미 있음 {src:야마}

#### 9.2.3.b Activator의 구조와 DNA-binding domain
- activator = 독립된 두 domain: [[DNA-binding domain|DBD|DNA binding domain]] + [[activation domain|활성화 도메인|활성 도메인]] {fire:25-13} {src:야마,vault,기출}
- DBD는 regulatory DNA sequence([[cis-acting element|cis|cis-acting]])에 결합 / activation domain은 [[Mediator|미디에이터]], general TF, RNA polymerase와 interaction해 전사 stimulation {fire:19-10/20-10} {src:야마,vault,기출}
- activation domain이 작용하는 대상(2020 그림 빈칸): [[general transcription factors|general transcription factor|GTF]]와 [[chromatin structure|chromatin]] {fire:19-10/20-10} {src:야마,기출}
- human genome에는 약 [[2000|2,000|2천]]개의 TF가 encode됨 (전체 약 2만 2천 유전자의 1/10) / 두 domain이 독립적으로 기능한다는 점을 이용한 실험 = yeast [[two-hybrid|2-hybrid|twohybrid]] (심화) {src:야마}
- DBD 4종: [[zinc finger|zincfinger|징크핑거]] · [[helix-turn-helix|hth|helixturnhelix]] · [[leucine zipper|leucinezipper|류신지퍼]] · helix-loop-helix(다음 줄들에서 확인) {fire:17-4/20-11/21-7/22-7/23-7/25-8} {star:교수 강조 - 특징적인 네 가지 구조} {src:야마,vault,기출}
- zinc finger: [[zinc|Zn|아연]] ion을 잡아 finger 모양, α helix + β sheet / 예 [[TFIIIA]], [[Sp1]], steroid hormone receptor {fire:22-7/25-8} {src:야마,vault,기출}
- helix-turn-helix: α helix 하나가 DNA [[major groove|주홈|major]]에 접촉하고 나머지가 안정화 / 예 [[homeodomain|homeodomain protein|호메오도메인]] protein (발생 중 유전자 발현) {src:야마,vault}
- leucine zipper: 두 polypeptide helix의 [[leucine|류신]] hydrophobic interaction이 zipper처럼 결합 → dimer / 예 [[AP1|AP-1]] (Jun, Fos) {fire:22-7/25-8} {src:야마,vault,기출}
- helix-loop-helix: 두 polypeptide가 [[loop|루프]]로 이어진 helix로 결합 (loop가 flexibility) → dimer {src:야마,vault}
- dimer를 이루는 DBD 두 가지 = [[leucine zipper]] + [[helix-loop-helix]] (같은 family의 서로 다른 member끼리도 dimer → 조합으로 factor 종류 확장) {fire:18-5} {src:야마,기출}
- AP-1은 Jun–Jun, Jun–Fos dimer는 가능하나 [[Fos–Fos|Fos-Fos|fosfos]]는 불가 {src:야마}
- steroid hormone receptor: cholesterol 유래 hormone이 세포막을 통과해 세포 안 receptor(nuclear receptor superfamily)에 결합, receptor가 DNA에 붙어 [[TF|전사인자|transcription factor]]로 작용 {src:야마}

#### 9.2.3.c Activation domain이 전사를 촉진하는 방법
- 방법 1: [[Mediator|미디에이터]] 및 [[general transcription factor|GTF|general TF]]와 protein–protein interaction으로 pre-initiation complex에 직접 작용 {fire:19-10/20-10} {src:야마,vault,기출}
- Mediator = enhancer의 activator와 [[RNA polymerase II|Pol II|pol2]]를 이어 주는 큰 복합체 {src:야마,vault}
- 방법 2: coactivator와 interaction해 chromatin structure modify → coactivator = [[HAT|histone acetyltransferase]] 활성 → histone [[acetylation|아세틸화]] → chromatin [[relax|이완|풀림]] {fire:21-10/22-10/23-9/25-10} {src:야마,vault,기출}
- 방법 3: [[chromatin remodeling factor|remodeling factor|chromatin remodeling]]를 가져와 nucleosome rearrangement (9.3.2) {src:vault}
- coactivator의 효소 활성 = [[HAT]], 작용 후 lysine charge = [[0]] {fire:22-10/23-9/25-10} {src:야마,vault,기출}
- corepressor의 효소 활성 = [[HDAC]], 작용 후 lysine charge = [[+1|1|양전하]] {fire:22-10/23-9/25-10} {src:야마,vault,기출}

#### 9.2.3.d Repressor
- passive repressor: activator가 붙을 자리에 대신 결합해 [[competition|경쟁|경쟁적 결합]] → [[DNA-binding domain|DBD|DNA binding domain]]만 있으면 됨 {fire:18-2} {src:야마,vault,기출}
- active repressor: DBD와 [[repression domain|repression|억제 도메인]]을 가져 activator·Mediator·GTF와의 protein–protein interaction으로 initiation 차단 {src:야마,vault}
- corepressor와 interaction → chromatin 변형: corepressor = [[HDAC|histone deacetylase]] 활성 → deacetylation → chromatin [[compact|condensed|응축|치밀]] {fire:21-10/22-10/23-9/25-10} {src:야마,vault,기출}
- deacetylation 후 lysine 양전하가 [[+1|1|복원]]로 회복되어 DNA와의 전기적 결합이 다시 강해짐 {src:야마}

### 9.2.4 Regulation of elongation
- (Ch8 GTF) initiation: TFIIH가 CTD의 [[Ser5|serine5|serine-5|S5]]을 인산화하면서 Pol II 출발 {src:야마,vault}
- 출발 후 약 [[50|50nt|~50]] nt 안에서 멈춤 (promoter-proximal pausing, 신호가 오면 바로 이어 갈 [[poised|준비된|poised state]] 상태) / 세균 σ 이탈은 약 10 nt로 구분 {src:야마,vault}
- 멈추게 하는 negative regulation 인자 = [[NELF]] (negative elongation factor) + [[DSIF]] (DRB sensitivity-inducing factor) {fire:17-5/21-11/22-11/23-10/25-11} {star:거의 매년 3가지로 출제} {src:야마,vault,기출}
- 풀어 주는 positive regulation 인자 = [[P-TEFb|ptefb|positive transcription-elongation factor-b]] {fire:17-5/21-11/22-11/23-10/25-11} {src:야마,vault,기출}
- P-TEFb가 인산화하는 세 곳 = [[NELF]], [[DSIF]], CTD의 [[Ser2|serine2|serine-2|S2]] {src:야마,vault}
- 결과: NELF는 [[떨어져 나감|해리|dissociate|release]], 그 자리에 P-TEFb가 붙고 DSIF는 인산화된 채 남아 elongation 촉진 → CTD에 elongation factor·processing factor가 더 결합하여 [[productive elongation|productive]] elongation {src:야마,vault}
- CTD kinase 둘의 구분: TFIIH = Ser[[5]] (initiation) / P-TEFb = Ser[[2]] (elongation) {src:야마,vault}
- CTD에 processing factor가 붙어 있어 pre-mRNA가 만들어지자마자 5′ [[capping|cap]], splicing, poly-A 부가가 함께 진행 (Ch8) {src:야마,vault}
- 구분: negative = NELF·DSIF, positive = P-TEFb (철자 주의: DSIF, P-TEFb) {fire:17-5/21-11/22-11/23-10/25-11} {src:야마,기출}

## 9.3 Chromatin and Epigenetics
> 같은 DNA라도 포장·표지로 켜고 끄며, 그 표지는 세포분열 후에도 전달된다

### Chromatin 기본 구조
- nucleosome core = [[147|147bp]] bp DNA가 histone [[octamer|옥타머|8량체]]를 감음 / octamer = H2A, H2B, H3, H4 [[각 2개|2개씩|2|두 개씩]] {fire:23-12} {src:야마,vault,PPT,기출}
- nucleosome core particle에 histone [[H1]] 한 분자가 결합 = [[chromatosome|크로마토솜]] (H1은 DNA를 묶어 안정화) {fire:23-12} {src:야마,vault,PPT,기출}
- nucleosome 직경은 약 [[11 nm|11nm|11]] {fire:23-12} {src:야마,기출}
- 전사가 일어나지 않는 compact한 영역 = [[heterochromatin|헤테로크로마틴]] / 풀려 있고 전사가 활발한 영역 = [[euchromatin|유크로마틴]] (Drosophila [[polytene|폴리틴]] chromosome에서 decondensed 영역) {src:야마,vault,PPT}
- chromatin 구조 변화의 두 요인: ① [[histone modification|히스톤 변형]] ② [[nucleosome rearrangement|nucleosome 재배치|chromatin remodeling]] {src:야마,vault,PPT}
- histone modification의 두 작용 방식: chromatin 구조·포장 상태 변화 + 특정 단백질의 [[binding site|결합 자리|결합 부위]] 제공 {src:야마,vault,PPT}

### 9.3.1 Histone modification
#### 9.3.1.a Histone acetylation
- histone N-terminal tail은 [[lysine|Lys|K|리신]]이 풍부해 acetylation이 쉽게 일어남 {fire:19-1} {src:야마,vault,PPT}
- acetylation → lysine의 positive charge가 [[중화|neutralize|0|없어짐]] → 음전하 DNA와의 결합력 ↓ → chromatin [[relax|이완|풀림]] → 전사 ↑ {fire:22-10/23-9/25-10} {src:야마,vault,PPT,기출}
- acetyl group을 붙이는 효소 = [[HAT|histone acetyltransferase]] (coactivator, 전사 [[활성|ON|촉진]]) {fire:16-21/17-9/18-6/19-11/20-12/21-10} {src:야마,vault,기출}
- acetyl group을 떼는 효소 = [[HDAC|histone deacetylase]] (corepressor, 전사 [[억제|OFF|저해]]) {fire:16-21/17-9/18-6/19-11/20-12/21-10} {src:야마,vault,기출}
- 전사 activator는 [[HAT]], repressor는 [[HDAC]]와 연결 / histone tail은 K·R이 많아 +, DNA는 phosphate 때문에 – 전하 {src:야마,PPT}

#### 9.3.1.b Methylation 등 다른 변형과 H3 tail
- 그 밖의 변형: Lys·Arg [[methylation|메틸화]], Ser [[phosphorylation|인산화]], Lys에 [[ubiquitin|유비퀴틴]]·SUMO 첨가 {src:야마,vault,PPT}
- H3K[[4]] methylation → active / H3K[[9]], H3K[[27]] methylation → inactive(heterochromatin) {fire:22-12/23-11/25-12} {star:교수 강조 - K9·K27 특히 중요} {src:야마,vault,기출}
- H3K9 acetylation과 H3S10 phosphorylation은 [[active|활성]] 표지 → 같은 K9라도 acetylation이면 active, methylation이면 [[inactive|비활성|억제]] {src:vault}
- methylated H3K9·K27은 chromatin condensation·heterochromatin 형성 단백질의 binding site / H3K9me에 붙어 heterochromatin을 만드는 단백질 = [[HP1]] {src:PPT}
- 변형의 조합이 신호로 읽힌다는 개념 = histone [[code|코드|histone code]]
- Promoter의 H3K4 modification = [[trimethylation|trimethyl|H3K4me3|me3]] / Enhancer의 H3K4 modification = [[monomethylation|monomethyl|H3K4me1|me1]] {fire:18-10/19-12/20-13/23-13/25-14} {star:교수 강조} {src:야마,vault,PPT,기출}
- 유전자 활성화 시 promoter·enhancer의 nucleosome이 제거·재배치 → TF 접근 용이 → 열린 chromatin은 DNase I에 잘 잘리는 DNase [[hypersensitive|과민|hypersensitive site]] site {fire:19-12} {src:야마,vault,PPT}

### 9.3.2 Chromatin remodeling factors
- chromatin remodeling factor = DNA와 histone 사이의 접촉을 바꾸는 protein [[complex|복합체]] (= nucleosome rearrangement) {src:야마,vault,PPT}
- 하는 일 3가지: nucleosome을 [[reposition|재배치|이동]] / conformation 변화 / DNA에서 [[eject|제거|방출|빼냄]] {src:야마,vault,PPT}
- ATP를 써서 nucleosome을 밀거나 빼는 대표 복합체 = [[SWI/SNF|swisnf]]
- activator가 remodeling factor를 데려와 nucleosome을 이동·제거 → GTF·RNA pol가 접근 가능해져 [[전사|transcription]]가 일어남 {src:야마}
- elongation factor = 개시 후 elongation에 관여하는 인자로 Pol II [[CTD|C-terminal domain]]의 인산화 상태에 따라 Pol II에 모임 {src:야마,vault,PPT}
- elongation factor에는 [[histone modifying enzyme|histone modifying enzymes]]와 [[chromatin remodeling factor|chromatin remodeling factors]]가 포함됨 {src:야마,vault,PPT}

### 9.3.3 Histones and epigenetic inheritance
#### 9.3.3.a Histone modification의 유전
- [[epigenetic inheritance|후성유전|epigenetics]] = DNA 서열에 없는 정보의 전달 / 대표 기전 세 가지 = [[histone modification|히스톤 변형]], [[DNA methylation|DNA 메틸화]], noncoding RNA {fire:16-22/18-7/23-14} {star:영어 이름 + 메커니즘 (1-53:30)} {src:야마,vault,PPT,기출}
- modified histone이 복제 후 두 [[progeny|딸|자손]] chromosome으로 나뉘어 전달되고, 새 histone도 비슷하게 modification됨 → 변형 패턴 유지 (modified histone이 변형 효소의 binding site가 됨) {src:야마,PPT}
- 예: Drosophila의 특정 regulatory gene은 발달 중 repress되고 다음 분열·세대에도 유지 ← H3 [[lysine 27|K27|Lys27|리신 27]] methylation by [[Polycomb|Polycomb protein|PcG]] protein {fire:17-10/18-8/21-12/22-12/23-11/25-12} {src:야마,vault,PPT,기출}
- [[PRC1|polycomb repressive complex 1]] = methylated H3K27에 binding / [[PRC2|polycomb repressive complex 2]] = H3K27을 methylation {fire:17-10/18-8/20-14/21-12/22-12/23-11/25-12} {star:교수 강조} {src:야마,vault,PPT,기출}
- 정리 세트: H3K27 methylation → [[inactive|비활성|억제]] chromatin / 인지하는 단백질 = [[PRC1]] / 주위 histone modification을 일으키는 단백질 = [[PRC2]] {fire:17-10/18-8/21-12/22-12/23-11/25-12} {src:야마,기출}
- PRC2가 인접 nucleosome을 계속 methylation → H3K27 methylation이 [[spread|퍼짐|확산|spreading]]되어 세포분열 후에도 유지 {src:야마,PPT}
- 같은 후성유전의 예: 당뇨 obesity model mouse에 [[folic acid|엽산|folate]]를 먹이면 DNA 서열 변화 없이 당뇨가 없어지고 자손에게도 유지 (심화) {src:야마}

#### 9.3.3.b DNA methylation
- [[CpG|CG|cpg island]] dinucleotide의 cytosine 5-carbon에 methyl → [[5-methylcytosine|5mC|5-메틸시토신]] → 전사 [[억제|repression|repress]] / CpG의 p = phosphodiester bond (상보 결합 아님) {fire:17-8/21-8/23-14} {src:야마,vault,PPT,기출}
- 복제 후 methylated parental strand와 수소결합한 daughter strand의 CpG도 methylation → [[maintenance|유지]] methylation → 후성유전 {star:영어 이름 + 메커니즘 (1-53:30)} {src:야마,vault,PPT}
- DNA methylation의 역할 ①: [[transposable element|transposon|전위인자|전이인자]]에서 흔하며 그 이동을 억제 {fire:17-8/21-8/23-14} {src:야마,vault,PPT,기출}
- 역할 ②: 포유동물의 [[development|발생|발달]]·differentiation 관련 유전자의 전사를 억제 {fire:23-14} {src:야마,vault,PPT,기출}
- DNA methylation이 대표하는 두 현상 = [[genomic imprinting|imprinting|유전체각인]] + transposable element 이동 [[억제|저해|inactivation]] {fire:17-8/21-8/23-14/25-15} {src:야마,기출}
- methylation의 복구: [[TET|TET family]] enzymes가 5-methylcytosine을 산화 → 5-[[formylcytosine|5-formylcytosine|formyl]] + 5-[[carboxylcytosine|5-carboxylcytosine|carboxyl]]cytosine {src:야마,vault,PPT}
- 이 두 산물은 [[base-excision repair|BER|base excision repair]]로 제거되고 cytosine으로 교체됨 {src:야마,vault,PPT}

#### 9.3.3.c Genomic imprinting
- genomic imprinting = 유전자가 [[부모|mother or father|모계 부계|부모 중 누구]]에게서 왔는지에 따라 발현이 결정되는 현상, 핵심 기전 = DNA [[methylation|메틸화]] {fire:18-11/19-14/20-15} {star:영어 이름 + 메커니즘 (1-53:30)} {src:야마,vault,PPT,기출}
- Gene [[H19]]: [[maternal|모계|엄마]] allele만 발현 (부계 H19는 methylated, 수컷 germ cell 발달 중 methylation) {fire:20-15/19-14} {src:야마,vault,PPT,기출}
- Gene [[Igf2|IGF2|igf-2]]: [[paternal|부계|아빠]] allele만 발현, 태아 성장에 필수인 growth factor {src:야마,vault}
- Gene [[p57]]: cell cycle를 억제하는 gene, paternal allele의 promoter가 methylated되어 꺼지고 [[maternal|모계]] allele만 발현 {src:야마,vault}
- 해석: paternal allele은 자손이 크도록(Igf2), maternal allele은 성장을 inhibit하도록(H19·p57) 방향 지어져 있음 {src:야마}
- 난자만으로 발생을 시작하면 maternal set만 2개 → 성장에 필수인 Igf2가 꺼지고 H19가 과발현되어 초기 배아 사망 / 난자의 H19를 제거하면 옆 Igf2가 켜져 더 오래 생존 {src:야마}

#### 9.3.3.d Noncoding RNA와 X inactivation
- noncoding RNA = ORF가 없어 단백질을 만들지 못하지만 자체 기능을 가짐 / 예: [[miRNA|microRNA]]와 [[lncRNA|long noncoding RNA|lnc RNA]] {src:야마,vault,PPT}
- miRNA는 약 [[20-30|20~30|20–30]] nucleotide, RNA interference pathway로 translation을 [[억제|inhibit|저해]]하거나 homologous mRNA의 [[degradation|분해]]를 유도 {src:야마,vault,PPT}
- lncRNA는 [[200|200nt]] nucleotide 초과, chromatin을 modify하는 protein과 complex를 이루어 이를 transcription site로 이끌어 주변 유전자의 발현 조절 {src:야마,vault,PPT}
- lncRNA는 주로 [[PRC2]]와 complex를 이루어 target gene의 발현을 억제 (methylation) {fire:16-28/18-9} {star:영어 이름 + 메커니즘 (1-53:30)} {src:야마,vault,PPT,기출}
- [[Xist]] lncRNA → 포유류의 [[X chromosome inactivation|X inactivation|X 불활성화|xinactivation]] (여성의 두 X 중 하나를 완전히 inactive) / 일부 lncRNA는 imprinting에도 관여 {fire:23-14/25-15} {star:영어 이름 + 메커니즘 (1-53:30)} {src:야마,vault,PPT,기출}
- 일부 lncRNA는 먼 target gene에 chromatin-modifying complex를 불러오는 [[trans]]-acting factor로 작용하며, repressor 또는 [[activator|액티베이터]] 모두 가능 {src:야마,PPT}
- 생명현상 매칭(2025-15): histone modification → [[epigenetic inheritance|후성유전]] / DNA methylation → genomic imprinting·transposon 억제 / lncRNA → [[X inactivation|X chromosome inactivation|X 불활성화]] {fire:23-14/25-15} {src:야마,기출}
