## 10.1 Translation of mRNA
> mRNA를 읽어 단백질을 만든다 — 재료(tRNA·ribosome·mRNA) → 개시 → 신장·종결 → 조절

### 10.1.1 Structure of tRNAs and aminoacyl-tRNA synthetase
- mRNA는 [[5′→3′|5'→3'|5to3]] 방향으로 읽히고, polypeptide는 [[N→C|amino→carboxy|N-terminus에서 C-terminus]] 방향으로 합성된다 {src:PPT,야마}
- tRNA 길이 = [[70~80|70-80|7080]] nt → 2D [[cloverleaf|클로버잎|클로버]] 구조 → 3D [[L|L자|L-shape]]자 모양 (ribosome에 맞게 compact) {src:vault,야마,PPT}
- ⭐ tRNA의 두 핵심 부위: 3′ [[CCA]] 말단 맨 끝 [[adenosine|A|아데노신]]의 ribose에 아미노산이 공유결합 / [[anticodon loop|anticodon|안티코돈 루프]]가 mRNA codon에 결합 {fire:16/25-1} {star:교수 '중요한 2가지 부분'} {src:vault,야마,PPT}
- tRNA의 기능 2가지 (2025-1): 아미노산과 결합해 [[운반|transport|carry]] + mRNA의 [[codon|코돈]]과 결합 {fire:25-1} {src:야마,기출}
- 아미노산을 tRNA에 붙이는 효소 = [[aminoacyl-tRNA synthetase|aminoacyl tRNA synthetase|synthetase]] → 종류 수 = 아미노산 수 = [[20|20개|20종]] {fire:17/18/19/20/25} {src:vault,야마,PPT}
- (심화) ATP가 관여하는 합성 효소는 [[synthetase]], ATP가 관여하지 않으면 synthase {src:야마}
- 1단계: 아미노산의 [[carboxyl|카복실|carboxyl group]]기(nucleophile)가 ATP의 [[α|alpha|알파]]-phosphate(electrophile)를 공격 → aminoacyl-AMP + [[PPi|pyrophosphate|diphosphate]] {src:vault,야마,PPT}
- 2단계: tRNA 3′ adenosine의 [[3′-OH|3'oh|OH|hydroxyl]](nucleophile)가 aminoacyl기의 [[carbonyl carbon|carbonyl C|카보닐 탄소|carbonyl]](electrophile)를 공격 → [[AMP]] 이탈 → aminoacyl-tRNA(charged tRNA) 완성 {src:vault,야마,PPT}
- 예: tRNA와 아미노산은 [[tyrosyl-tRNA synthetase|tyrosyl tRNA synthetase|TyrRS]]의 active site에서 만나고, 완성된 charged Tyr-tRNA는 synthetase에서 [[분리|해리|떨어짐]]된다 {src:vault}
- 🔴 Nucleophilic substitution = electron-rich한 [[nucleophile|친핵체]]가 electron-deficient한 electrophile을 공격해 새 공유결합을 만들고 [[leaving group|이탈기]]를 대체하는 반응 → synthetase · peptidyl transferase · release factor 세 반응의 공통 원리 {star:교수 강조} {src:vault,야마,PPT}

### 10.1.2 Codon and nonstandard codon-anticodon base pairing
- codon 조합 = 4×4×4 = [[64|64개]]개, 그중 단백질을 암호화하는 sense codon = [[61|61개]]개 (stop codon 3개 제외) {fire:22/23} {src:vault,야마,PPT}
- initiation codon = [[AUG]] → 아미노산 [[Met|methionine|메티오닌]] (원핵·진핵 모두 번역은 항상 이것으로 시작) {src:vault,야마,PPT}
- stop codon 3개 = [[UAA]] · [[UAG]] · UGA — 대응하는 tRNA가 없고 [[release factor|RF|eRF]]가 인식 {fire:23-3/22-16} {src:야마,기출}
- UGG(Trp)가 UGA로 바뀌면 그 지점에서 [[종결|termination|stop|번역 종결]]되어 앞까지만 합성된다 (기종평 2023-23: UGA = 종결 codon) {fire:23-기종평23} {star:교수 '외워놔야'} {src:vault,야마}
- 세포에는 tRNA가 약 [[40|40종|40개]]종뿐 → 61개 sense codon을 다 읽으려면 일부 tRNA가 여러 codon 인식 (cytosolic rRNA는 [[4|4종]]종) {fire:22-12/23-17} {src:야마,PPT,기출}
- 한 tRNA가 여러 codon을 읽는 현상 = [[wobble|워블]] : codon의 [[3번째|세 번째|third|3rd]] 염기에서 nonstandard base pairing 허용 {fire:16/25-2} {src:vault,야마,PPT}
- wobble은 anticodon의 [[첫 번째|first|1번째|5′ 끝]] 염기(특정)가 codon의 세 번째 염기(여러 종류)와 짝짓는 것 {src:야마}
- Phe-tRNA anticodon의 [[G]]는 codon의 C뿐 아니라 [[U]]와도 짝 (G≡C 외에 G=U) {src:vault,야마,PPT}
- Ala-tRNA의 modified base inosine(I)는 codon의 [[A]] · [[C]] · [[U]]와 짝 (I=A/C/U) {fire:17/18/19/20/21/22/23/25} {src:vault,야마,PPT,기출}
- anticodon의 U는 codon의 [[A]] · [[G]]와 짝 (2023-7: 시험지에는 U 대신 I로 오타 → 정답 U·C·A) {fire:23-7} {src:야마,기출}

### 10.1.3 Ribosome structure
- 모든 ribosome은 [[2|두|2개]]개의 subunit (large + small)를 가지며, 각 subunit = [[rRNA]] + ribosomal protein 복합체 {src:vault,야마,PPT}
- 원핵: 50S + 30S → [[70S|70]] ribosome / 진핵: 60S + 40S → [[80S|80]] ribosome {fire:15} {src:vault,야마,PPT}
- 원핵 small subunit의 rRNA = [[16S|16s|16]] / 진핵 small subunit의 rRNA = [[18S|18s|18]] {fire:21} {src:vault,야마,기출}
- 진핵 large(60S) subunit의 rRNA = [[28S]] · [[5.8S]] · 5S / 원핵 large(50S) = 23S · 5S {src:vault,야마}
- S = [[Svedberg|svedbergunit|스베드베리]] unit = [[sedimentation rate|침강계수|침강 속도|sedimentation]] → 단순히 분자량에 비례하지 않는다 {src:vault,야마,PPT}
- ⭐ 왜 60S + 40S = 80S ≠ 100S? S값은 분자량 외 요인(점도 등)과 입자의 [[shape|형태|모양]]에 영향을 받고, ribosome은 완벽한 [[구형|sphere|sphere 아님]]이 아니기 때문 {fire:25-3} {star:교수 수업 중 질문} {src:야마,기출}
- Ribosome 분리: HeLa lysate를 [[sucrose|sucrose density gradient]] density gradient에 올려 [[ultracentrifugation|초원심분리]] → S가 큰 입자일수록 아래쪽으로 / rRNA는 UV([[260|260nm]] nm)를 흡수해 흡광도 peak로 확인 {src:vault,야마,PPT}
- 흡광도 peak 순서: 40S → 60S → [[80S]] → 그 뒤의 작은 peak들 = [[polysome|polyribosome|폴리솜]] {src:vault,야마}
- rRNA의 기능 2가지 = structural [[scaffold|스캐폴드|뼈대]] + catalytic activity ([[ribozyme|리보자임]]; large subunit의 [[peptidyl transferase]]) {fire:16/17/18/25} {src:vault,야마,PPT,기출}
- 사람 80S ribosome (cryo-EM, HeLa) = ribosomal protein 약 [[80|80개]]개 + rRNA [[4|4종]]종 / 단백질 이름 uL18의 u = [[universal|유니버설]], L = large subunit (e = eukaryotic) {src:PPT,야마}

### 10.1.4 Organization of mRNAs and signals for translation initiation
- 번역되지 않는 양 끝 부위 = [[UTR|untranslated region]] (5′ UTR, 3′ UTR) {src:vault,야마,PPT}
- 진핵 mRNA는 대부분 [[monocistronic|mono-cistronic|모노시스트로닉]], 원핵 mRNA는 [[polycistronic|poly-cistronic|폴리시스트로닉]] → 각 유전자마다 독립된 개시 서열 {src:vault,야마,PPT}
- 진핵 mRNA 보호: 5′ 끝 = [[7-methylguanosine|m7G|7-methylguanosine cap]] cap / 3′ 끝 = [[poly-A|polyA|poly A]] tail {fire:17/18/19/20/22/23} {src:vault,야마,PPT}
- cap과 poly-A tail의 공통 역할 3가지: [[exonuclease|엑소뉴클레아제]] 분해 방지 · [[nuclear export|핵외수송|핵 수송|export]] 촉진 · translation 촉진 {fire:} {src:vault,야마,PPT}
- ribosome이 initiation factor를 매개로 직접 recruit되는 자리 = 5′ [[cap]] (poly-A의 PABP는 eIF4G를 통한 간접 연결) (기종평 2023-3: 정답 5′ capping) {fire:23-3/22-16} {src:야마,기출}
- 원핵 개시 signal = [[Shine-Dalgarno|shinedalgarno|SD]] sequence (5′-[[AGGAGG]]-3′), small subunit의 [[16S]] rRNA 3′ 말단 부근과 상보적 {fire:17/21} {src:vault,야마,PPT}
- 원핵은 5′ end 또는 polycistronic mRNA 내부의 SD에서도 개시 가능 / 진핵은 5′ cap에 결합한 factor를 매개로 40S가 recruit된 뒤 5′→3′ [[scanning|스캐닝]] → 첫 [[AUG]]에서 개시 {fire:18/19/20} {src:vault,야마,PPT}
- 🔴 [[IRES|internal ribosome entry site]] = 일부 virus·진핵 mRNA에서 5′ cap과 [[무관|관계없이|독립|independent]]하게 ribosome이 mRNA 내부에 결합하는 서열 {src:vault,야마,PPT}
- IRES 결합 방식 2가지: ① [[eIF4A]]와 복합체를 이룬 [[eIF4G]]가 IRES를 인식 → 40S 결합 / ② [[40S]] subunit이 IRES를 직접 인식 {src:vault,야마,PPT}
- virus는 숙주의 cap-dependent translation이 억제된 상황에서도 자기 mRNA를 번역하려고 IRES를 쓴다 / 진핵세포도 [[stress|스트레스]] 상황에서 복잡한 개시를 피해 IRES를 쓰기도 함 {src:야마}

### 10.1.5 Translation of mRNA
#### Initiation
- 번역 3단계 = [[initiation|개시]] → [[elongation|신장]] → [[termination|종결]] {src:vault,야마,PPT}
- 개시 전에 mRNA는 이미 [[eIF4|eIF4 complex]]와 결합해 있다 (2022-3·2023-8 정답 4번) {fire:22-3/23-8} {src:야마,기출}
- ① eIF1 · eIF1A · [[eIF3]]이 40S subunit에 결합 {fire:16} {src:vault,야마,PPT}
- ② Met-tRNA를 40S로 데려오는 것 = [[eIF2|eif-2]]–GTP (eIF5와 함께 40S에 결합) {fire:25-5/23/22/20} {star:교수 질문} {src:vault,야마,기출}
- ③ eIF4 complex = [[eIF4E]](5′ cap에 결합) + [[eIF4G]](eIF4E·eIF4A·PABP를 연결) + eIF4A + eIF4B / PABP가 poly-A tail에 결합 → mRNA가 [[loop|고리|원형|closed loop]] 구조 {fire:21/22/23} {src:vault,야마,PPT}
- ④ scanning에서 RNA 2차 구조를 푸는 [[eIF4A]] = ATP-dependent RNA [[helicase|헬리카제]] {src:vault,야마,PPT}
- ⑤ 40S가 첫 AUG를 인식하면 [[eIF5]]([[GAP|GTPase-activating protein|GTPase activating protein]])가 eIF2-GTP의 GTP 가수분해를 유도 → eIF2-GDP와 다른 initiation factor들이 40S에서 분리 {fire:25-6} {src:vault,야마,기출,PPT}
- ⑥ [[eIF5B]]-GTP가 60S subunit을 운반해 40S complex에 결합시킴 (GTP → GDP) {fire:22/23} {src:vault,야마,PPT}
- 떨어진 eIF2-GDP를 eIF2-GTP로 되돌리는 교환 인자(GEF) = [[eIF2B|eif2b]] {fire:17/18/19/20/21/22/23} {src:vault,야마,기출}
- eIF2와 eIF5B의 GTP 가수분해는 conformation 변화를 일으켜 결합했던 물질과 [[분리|해리|dissociation]]시킨다 (GTP형 = 결합·운반, GDP형 = 해리) {src:야마,PPT}
- 인자 수: 진핵 eIF 약 [[12|12개]]개 / eEF [[3|3개]]개 / eRF [[2|2개]]개 → initiation이 가장 복잡 / 원핵은 IF·EF·RF 각 3개 (IF1-3, EF-Tu·EF-Ts·EF-G, RF1-3) {src:vault,야마,PPT}
- ⭐ 왜 initiation이 elongation·termination보다 복잡한가? ① 잘못 만들었을 때 [[비용|cost|에너지 낭비]]이 커서 처음부터 정확해야 함 ② ribosome을 mRNA에 [[처음|first|최초]] 결합시켜 정확한 AUG에 위치시켜야 함 {fire:} {star:교수 질문 슬라이드} {src:vault,야마,PPT}

#### GTPase · GAP · GEF 총정리
- GTPase (GTP→GDP+Pi 가수분해): 개시 = eIF2 · [[eIF5B]] / 신장 = [[eEF1α|eef1alpha|eef1a]] · eEF2 {fire:22-11/23-16} {src:야마,기출}
- GAP (GTPase 가수분해 촉진) = [[eIF5]] (신장 쪽에는 없음) {fire:23-10} {src:야마,기출}
- GEF (GDP→GTP 교환): 개시 = [[eIF2B]] / 신장 = [[eEF1βγ|eef1betagamma|eef1bg]] — 하는 일은 같고 표적만 다름 (eIF2 / eEF1α) {fire:17/18/19/20/21/22/23} {src:야마,기출}
- eIF5B · eIF2 · eEF1α · eEF2의 공통점 = [[GTP]] 결합 단백질로, 구조가 바뀌며 운동성을 가진다 (ATP 결합·tRNA 운반 등은 오답) {fire:22-11/23-16} {src:야마,기출}
- eEF1βγ와 eIF2B의 공통점 = [[GEF]] 단백질 (GAP 아님; 2023-10 시험지의 eIF2는 eIF2B의 오타) {fire:22-5/23-10} {src:야마,기출}

#### Elongation
- ribosome의 3 site: [[A|aminoacyl]] site = aminoacyl, [[P|peptidyl]] site = peptidyl, [[E|exit]] site = exit {src:vault,야마,PPT}
- 개시 후 Met-tRNA는 [[P]] site에 위치, 다음 aminoacyl-tRNA는 [[A]] site에 결합 {src:vault,야마,PPT}
- 다음 aa-tRNA를 A site로 운반 = [[eEF1α|eef1alpha|eef1a]]·GTP (원핵 [[EF-Tu|eftu]]) → 올바른 짝이 들어오면 conformational change → GTP 가수분해 → eEF1α-GDP가 분리 {fire:20/22/23/25} {src:vault,야마,PPT}
- eEF1α-GDP를 다시 GTP형으로 바꿔 주는 GEF = [[eEF1βγ|eef1betagamma|eef1bg]] (원핵 [[EF-Ts|efts]]) {fire:17/18/19/20/21/22/23} {src:vault,야마,PPT}
- peptide bond 형성 = [[large|60S|large subunit]] subunit rRNA의 [[peptidyl transferase|peptidyl transferase 활성|ribozyme]] 활성 (RNase H·P 아님) {fire:17/18/25} {src:vault,야마,PPT}
- A site 아미노산의 [[amine|amino|아민|NH2]] N이 P site 아미노산의 [[carbonyl|카보닐]] C를 nucleophilic attack → 사슬이 P site tRNA에서 [[A|A site]] site tRNA로 전달 {src:vault,야마,PPT}
- translocation = [[eEF2|eef-2]]·GTP가 ribosome을 [[3|3 nt|1 codon]] nt(1 codon) 이동시킴 (GTP 가수분해; 원핵 [[EF-G|efg]]) {fire:22/23} {src:vault,야마,PPT}
- translocation 후 P site의 (빈) tRNA는 [[E]] site로 이동해 방출, A site tRNA는 [[P]] site로 이동 {fire:17} {src:야마}
- 번역 정확도: 오류율 10의 −[[3|3승]]승 미만 — 염기쌍 형성만으로는 설명 불가 → proofreading {src:vault,야마,PPT}
- proofreading ①: small subunit의 [[decoding center|decodingcentre]]에서 rRNA가 올바른 codon–anticodon 염기쌍(Watson–Crick geometry)만 안정적으로 인식, 틀린 aa-tRNA는 안정 결합 못함 {src:vault,야마,PPT}
- proofreading ②: 올바른 aa-tRNA가 A site에 들어오면 ribosome의 conformational change가 일어나 eEF1α-GTP의 [[가수분해|hydrolysis]]를 유도 {src:야마,PPT}

#### Termination
- elongation은 [[stop codon|종결 코돈|정지 코돈]]이 A site로 translocation될 때까지 진행 {src:vault,야마,PPT}
- A site의 stop codon에는 tRNA가 아니라 [[release factor|releasefactor|RF|eRF]](진핵 [[eRF1]]·eRF3; 원핵 RF1·2·3)가 결합 {fire:16/25-7} {src:vault,야마,기출,PPT}
- stop codon에 대응하는 tRNA는 [[없다|없음|존재하지 않는다]] (「stop codon tRNA에 아미노산이 붙어 있다」는 오답 선지) {fire:22-16/23-3} {src:야마,기출}
- RF1은 stop codon(UAA·UAG·UGA)을 인식, 핵심 motif = [[GGQ|Gly-Gly-Gln]] {src:vault,야마,PPT}
- RF의 GGQ 중 Gln이 [[H2O|물|water]](nucleophile)를 P site tRNA–polypeptide 결합의 carbonyl C 가까이 위치시킴 → nucleophilic attack으로 결합 [[가수분해|hydrolysis]] {src:vault,야마,PPT}
- 결과: polypeptide가 방출되고 [[ribosome]]과 tRNA · mRNA · release factor가 모두 분리됨 {src:vault,야마,PPT}
- 하나의 mRNA에 여러 ribosome이 동시에 붙어 번역하는 구조 = [[polysome|polyribosome|폴리솜]] {src:vault,야마,PPT}

### 10.1.6 Regulation of translation
#### Repressor protein과 miRNA
- 번역 조절 3가지 = translational [[repressor]] protein · noncoding [[microRNA|miRNA]] · [[global|전체|전반]] translation regulation {src:야마,PPT}
- ferritin = 철을 [[Fe3+|Fe(III)|철3가]] 형태로 저장하는 [[24|24개]]-mer 구형 단백질 (outer shell + inner cavity) {src:vault,야마,PPT}
- 철 부족 → [[IRP|iron regulatory protein]]가 ferritin mRNA 5′ UTR의 [[IRE|iron response element]]에 결합 → 40S 결합 방해 → 번역 [[OFF|억제|차단|off]] {src:vault,야마,PPT}
- 철 충분 → IRP가 IRE에 결합 [[안 함|하지 않음|못함]] → ferritin 번역 진행 (철을 줄이려 ferritin을 안 만든다는 선지는 오답) {fire:22-16/23-3} {src:야마,기출}
- 철 결핍성 빈혈에서는 혈중 ferritin이 [[낮다|감소|낮음]] → 진단에 이용 (기종평 2025-9: ferritin deficiency anemia는 misfolding disease가 아님) {fire:25-9} {src:야마,PPT}

## 10.2 Protein Folding and Processing
> 선형 사슬이 붐비는 세포질에서 제대로 접히게 — 실패하면 병

### 10.2.1 Protein folding and the proteostasis network
- 합성된 선형 polypeptide가 붐비는 cytosol에 노출되면 hydrophobic side chain이 물에 [[exposed|노출|exposure]] → [[aggregation|응집]] ⭐(수업 질문) {fire:} {star:교수 질문 슬라이드} {src:야마,PPT}
- 소수성 아미노산 예: [[Val]] · Leu · [[Ile]] · Met · [[Phe]] · Trp {src:야마}
- proteostasis network ≈ [[2000|2,000|2천]]개: ~400 synthesis·de novo folding + ~[[300]] chaperone + ~[[1000|1,000]] degradation (UPS·autophagy-lysosomal) {src:vault,야마,PPT}
- 세포 크기가 일정하므로 input([[synthesis|합성]])과 output([[degradation|분해]])의 균형이 맞아야 하며, 각 단백질에는 고유한 lifetime([[turnover|회전율]])이 있다 {src:야마,PPT}
- 새로 합성된 사슬은 다른 단백질 도움 없이 folding [[intermediate|중간체]]까지 도달하나, 불안정한 intermediate는 misfolding·aggregation 위험 {src:야마}
- aggregation 진행: monomer → misfolded monomer → dimer → [[oligomer|올리고머]] → [[protofibril|프로토피브릴]] → mature [[fibril|피브릴]] (병과 관련: oligomer~fibril) {src:vault,야마}
- 원인 4가지 (G.E.T.A) = genetic mutation · [[external stress|외부 스트레스]] (화학물질·ROS·열) · [[translational error|translation error|번역 오류]] · [[aging|노화]] {src:vault,야마,PPT} {star:교수 '아주 중요'}
- energy landscape: chaperone이 도우면 [[native state]]로 / 실패하면 off-pathway로 가서 amyloid fibril 축적 → 질병 {src:야마,PPT}
- amyloid = misfold되어 쉽게 분해되지 않는 단백질 덩어리 / 구조 확인 사이트 = UniProt, [[AlphaFold|AlphaFold server]] {src:야마,PPT}

### 10.2.2 Molecular chaperones
#### Chaperone의 종류와 HSP70
- ⭐ chaperone의 기능 (2025-8) = assists proteins in [[folding]] correctly and prevents [[aggregation]] (peptide bond 촉매·lysosome 분해·mRNA 수송은 오답) {fire:25-8} {src:vault,야마,기출}
- 3종류: [[Foldase]] (ATP 필요) · [[Holdase]] (ATP 불필요) · Disaggregase (ATP 필요/불필요 둘 다) {src:vault,야마,PPT}
- Foldase = unfolded 단백질을 올바른 conformation으로 folding / Holdase = free unfolded·folded 단백질에 결합해 [[soluble|가용성|용해]] 상태 유지 / Disaggregase = aggregate를 unfold해 solubilize {src:야마,PPT}
- 대표 chaperone [[HSP70|Hsp70|heat shock protein 70]] (70 kDa) = foldase, 열충격 후 발현이 [[증가|increase|up]]하고 단백질 [[변성|denaturation]]을 막아 준다 {fire:16/21/22/23} {src:vault,야마,기출}
- HSP70 domain: [[NBD|nucleotide binding domain]] (ATP/ADP 결합) + [[SBD|substrate binding domain]] (기질의 소수성 부위 결합, 뚜껑) {src:vault,야마,PPT}
- 순환: [[ATP]] 결합 → SBD 열림 → 기질 결합 → ATP 가수분해([[ADP]]) → SBD 닫힘(기질 보호·folding) → [[NEF|nucleotide exchange factor]]가 ADP를 ATP로 교환 → 뚜껑 열려 folded protein 방출 {fire:} {src:vault,야마,PPT}
- J-domain protein (JDP) = [[HSP40|hsp-40|DNAJ|J-domain protein]] : co-chaperone으로 다른 Hsp70을 과정에 데려옴 {src:야마,PPT}
- HSP70 SBD 구조: [[α|alpha]] subdomain = 뚜껑(lid) 역할 / [[β|beta]] subdomain = 기질이 결합하는 곳 {src:vault}
- NBD에 ATP가 결합하면 SBD 뚜껑이 [[열리고|열림|open]] 기질 친화도는 [[낮다|낮음|low]] (low-affinity) {src:vault}
- JDP(HSP40)가 non-native 기질을 전달 → α 뚜껑이 닫히며 [[Pi|inorganic phosphate|인산]]가 방출 → NEF가 ADP를 ATP로 교환하면 native 기질이 방출 {src:vault}

### 10.2.3 Co-translational folding
> 번역 중인 사슬에 chaperone이 붙어, 사슬이 완성되기 전의 misfolding·응집을 막는다
#### RAC (Ribosome-associated Complex)
- 번역 도중 ribosome 위의 nascent chain에 바로 folding이 일어나는 것 = [[co-translational|cotranslational]] folding → 합성이 끝나기 전 N-말단 부위의 misfolding·aggregation 방지 {src:vault,야마,PPT}
- ribosome-associated complex = [[RAC]] = ATPase [[비활성|inactive|활성 없는]] HSP70*(효모 SSZ1 / 사람 HSPA14) + HSP40([[ZUO1|DNAJC2]] (효모 ZUO1 / 사람 DNAJC2)) {src:PPT,야마}
- RAC 작동: HSP40이 large subunit의 tunnel [[exit|출구]] 근처에 결합 → HSP70*의 SBD가 nascent chain 접촉 → J-domain이 ATP-결합 상태의 활성 [[HSP70]]을 recruit → ATP 가수분해로 뚜껑이 닫혀 기질을 꽉 잡음 {src:PPT}
- HSP70의 conformational change에는 [[ATP hydrolysis|ATP 가수분해]]가 필요 {src:야마}

#### Mitochondrial precursor proteins (미토콘드리아)
- 세포질에서 합성된 mitochondria precursor protein은 [[Hsp70]]이 외막의 [[TOM|tom complex]] complex까지 운반 {fire:23-4} {src:vault,야마,PPT}
- 외막(OM)은 TOM, 내막(IM)은 [[TIM|tim complex]] complex로 통과 {src:야마}
- N-말단 [[presequence|presequence 신호]] (mitochondria 표적 신호) 는 matrix에서 [[MPP|mitochondrial processing peptidase]]가 절단 {src:vault,야마,PPT}
- matrix 안에서는 Hsp70과 Hsp[[60]]이 단백질의 folding을 도움 {src:vault,야마,PPT}

### 10.2.4 Protein misfolding (conformational) diseases

- HD: huntingtin 유전자는 [[4번|4|chromosome 4]] 염색체에 있고, 뇌 [[lateral ventricle|측뇌실|lateral ventricles]]이 커지며(enlargement), chorea는 [[dance|to dance|춤추다]]에서 온 말 {src:vault}
- ALS (Lou Gehrig병) = [[TDP-43|tdp43|TDP43]]의 cytoplasmic mislocalization·aggregation → [[motor neuron|운동뉴런|운동 뉴런]] 점진적 소실, 발병 후 3~5년 {src:vault,야마,PPT}
- ALS와 관련된 단백질 = [[SOD1|superoxide dismutase|SOD]](superoxide dismutase)와 TDP-43 {src:vault}
- Prion disease = [[prion|프리온|prion protein]] 단백질 (소 BSE · 양 [[scrapie]] · 사람 [[CJD|Creutzfeldt-Jakob]]) {fire:18/19/20} {src:vault,야마,기출}
- Huntingtin의 Cys 214 palmitoylation은 aggregation을 [[억제|inhibit|방지]]한다 (10.3.2 lipidation 연결) {src:PPT,야마}

#### 비신경퇴행성·전신 질환
- Type 2 diabetes = [[IAPP|amylin|islet amyloid polypeptide]]가 췌장 islet [[β-cell|beta cell|베타세포|β cell]]에서 응집 → β-cell 기능 저하·사멸 → insulin 분비 감소 {fire:25-9} {src:vault,야마,PPT}
- T2D: [[인슐린 저항성|insulin resistance]] → 혈당을 낮추려고 β-cell이 insulin과 IAPP를 더 많이 분비 {src:PPT}
- insulin이 proinsulin에서 만들어지듯 IAPP도 [[proIAPP]]에서 가공되어 생성됨 {src:vault}
- 백내장(Cataract) = 수정체 [[crystallin|크리스탈린]] 응집 (α·β·γ 세 종류) {fire:16/20/25-9} {src:vault,야마,PPT}
- [[α-crystallin|alpha-crystallin|alphacrystallin]]은 chaperone 역할 → 기능이 떨어지면 β/γ-crystallin 응집 증가 (노화 시 소실) {src:야마,PPT}
- α-crystallin 자체도 기질과 함께 또는 단독으로 [[aggregation|응집]]될 수 있다 {src:vault}
- AL amyloidosis = 면역글로불린 [[light chain|lightchain|light]]이 mutation으로 folding이 불안정해져 amyloid fibril이 되고 장기(심장·신장·간 등)에 축적 {src:vault,야마,PPT}
- AL: 환자의 70–80%에서 B cell clone이 [[λ|lambda]] light chain 생산, 가변부(IGLV) 유전자의 somatic mutation → 낮은 folding stability {src:PPT}
- 표 10.1 추가: injection-localized amyloidosis = [[insulin]] / Amyloid A amyloidosis = serum amyloid A / senile systemic amyloidosis = [[transthyretin|TTR]] {src:야마}
- 단백질 응집 질환이 아닌 것: [[Cancer|암|종양]] (2020~2023 거의 매년) · [[ferritin deficiency anemia|ferritin|ferritin 결핍 빈혈]] (2025-9) {fire:20/21/22/23/25-9} {src:기출,야마}

#### Amyloid fibril 검출 (염색)
- ⭐ 교수 강조(기종평 출제): amyloid fibril 검출 형광 dye 3가지 = [[Thioflavin T|ThT]] · [[Thioflavin S|ThS]] · [[Congo red|congored|콩고레드]] {star:교수 '기종평에 나온다'} {src:야마,PPT}

- Congo red: 조직 염색, 흡광 peak ~[[614]] nm / bright field에서는 [[빨간색|빨강|red]], fluorescence microscopy에서는 [[빨간 형광|빨강 형광|red fluorescence]] {src:vault}

- H&E 염색: hematoxylin은 음전하 산성 구조(nucleus·[[ribosome]]·rough ER), eosin은 [[양전하|positive|양전하(+)]] amino acid에 결합 {src:PPT}

### 10.2.5 Enzymes that catalyze protein folding
- 단백질 folding을 촉진하고 folding intermediate를 안정화해 chaperone처럼 작용하는 효소 2가지 = [[PDI]] · [[PPI]] {src:vault,야마,PPT}
- [[PDI|protein disulfide isomerase]] = ER에서 cysteine의 –SH를 disulfide bond([[S–S|ss|disulfide|이황화결합]])로 바꿈 {fire:15} {src:vault,야마,PPT}
- ER는 [[oxidizing|산화|산화적]] 환경이라 S–S 형성에 유리 / cytosol은 [[reducing|환원|환원적]] 환경이라 –SH 유지 → S–S는 주로 분비 단백질·일부 막 단백질에 존재 {src:야마,PPT}
- PDI는 잘못 형성된 disulfide bond를 끊고 다시 연결해 주는 [[isomerase|재배열|이성질화]] 기능도 한다 {src:야마}
- [[PPI|peptidyl prolyl isomerase]] = proline 앞 peptide bond의 [[cis–trans|cis-trans|cis trans]] isomerization 촉매 {src:vault,야마,PPT}
- proline은 ring 구조라 회전이 제한되어 chain이 꺾이고, cis↔trans 전환이 느려 folding의 [[rate-limiting|속도 결정|율속]] 단계가 될 수 있음 → PPI가 가속 {src:야마,PPT}
- 서술형 대비 (2018-9) 단백질 변형 종류: disulfide 형성 / peptidyl [[prolyl isomerization|prolyl isomerase|isomerization]] / [[proteolysis|protein cleavage]] / [[glycosylation]] / [[lipid attachment|lipidation]] {fire:18-9} {src:기출}

### 10.2.6 Protein cleavage (Proteolysis)
- 단백질 성숙을 위한 cleavage 3가지: [[NME|N-terminal methionine excision]] · [[signal sequence|signal peptide]] cleavage · insulin 가공 {src:vault,야마,PPT}
- NME: 새로 합성된 단백질의 N-말단 [[Met|methionine]]을 제거 (stability·folding·function 보장, co-translational) {src:야마,PPT}
- NME 효소 = [[methionine aminopeptidase|methionineaminopeptidase|metap]], 전체 단백질의 [[30~60|30-60|30–60]]%에서 일어남 {src:vault,야마,PPT}
- ER로 가는 단백질은 N-말단에 [[signal sequence|signal peptide]]를 가지며, ribosome에서 나오며 막 channel에 삽입되어 합성과 동시에 통과 = [[co-translational|cotranslational]] translocation {src:vault,야마,PPT}
- signal sequence 절단 효소 = [[signal peptidase|signalpeptidase]] (ER 막 단백질 분해효소) {fire:16-9} {src:vault,야마,기출,PPT}
- insulin = 두 사슬(A·B)이 disulfide로 연결 / 전구체에서 [[2|두|2번]]번 cleavage되어 성숙 {src:야마,PPT}
- preproinsulin (N-말단 signal + B chain + connecting peptide + A chain) →(signal 제거 + [[S–S|ss|disulfide|이황화결합]] 형성)→ [[proinsulin]] →([[C peptide|cpeptide|connecting peptide|C-peptide]] 제거)→ mature insulin {fire:15/16/19/20/23} {src:vault,야마,기출}
- signal peptide는 ER 표적 신호일 뿐 [[혈당 감지|혈당 농도 감지]] 기능이 아님 / 혈당이 높으면 췌장 [[β cell|β세포|베타세포]]에서 exocytosis로 분비 (endocytosis는 오답) {fire:19-10/20-10/23-6} {src:기출,야마}

## 10.3 Post-translational Modifications (PTMs)
> 화학기·단백질을 붙여 단백질의 활동·안정성·위치를 바꾼다

### PTMs overview (개요)
- PTM = 단백질이 합성된 뒤 일어나는 [[covalent|공유|공유결합]] 화학적 변형 / 영향: structure · function([[activity|활성]]) · interaction · [[localization|위치|세포 내 위치]] {src:vault,야마,PPT}
- ⭐ PTM의 목적 (2025-10) = regulate protein [[activity]], [[stability]] and [[localization]] (ASL) {fire:25-10} {src:vault,야마,기출}
- chemical group 부착형: [[phosphorylation|인산화]] (가장 흔함) · O-[[GlcNAcylation|O-GlcNAc]] · [[PARylation|PARylation]] · methylation · acetylation · oxidation {src:야마}
- ⚠ PARylation = poly(ADP-ribosyl)ation, 효소 [[PARP]] (교수님이 lipid라고 읽었으나 실제는 아님) {src:vault,야마}
- 단백질 부착형: [[ubiquitination|유비퀴틴화]] · [[SUMOylation|SUMO화]] / 그 외 [[proteolysis|단백질 절단]] (NME·signal peptidase·insulin) {src:야마}

### 10.3.1 Glycosylation
- Glycosylation = 단백질에 carbohydrate chain이 붙어 glycoprotein 형성 → folding · quality control · [[stability|안정성]] · [[transportation|수송|transport]]에 영향 {src:야마,PPT}
- N-linked glycosylation = [[Asn|asparagine|n|아스파라긴]]의 질소(N)에 당 결합 / O-linked = [[Ser|serine|s]] · Thr의 O에 당 결합 (Tyr 아님) {fire:19/20} {src:vault,야마,기출,PPT}
- N-linked 당 = Asn의 N에 [[N-acetylglucosamine|GlcNAc|N-acetylglucosamin]] 결합 / O-linked 당 = Ser·Thr의 O에 [[N-acetylgalactosamine|GalNAc|N-acetylgalactosamin]] 결합 {src:vault}
- glycosylation은 주로 [[ER|소포체|endoplasmic reticulum]]에서 일어남 → N-linked 당화가 있으면 그 단백질은 ER를 거친 것으로 추론 {src:vault,야마}
- N-linked는 번역이 끝나기 전([[co-translational|cotranslational]])부터 ER에서 시작 {src:PPT,야마}
- 올리고당은 ER 막의 지질 운반체 [[dolichol phosphate|dolichol|dolichol-phosphate]]에 먼저 조립된 뒤 Asn 잔기로 전달 {fire:19/20} {src:야마,기출,PPT}
- 이를 촉매하는 효소 = [[oligosaccharyltransferase|OST]] (OST) {src:야마,PPT}
- dolichol은 단백질에 지질을 전달하는 것이 아니라 [[당사슬|oligosaccharide|올리고당]]을 전달하는 carrier (2023-3 ⑤ 오답) {fire:22-16/23-3} {src:기출,야마}

### 10.3.2 Lipidation
#### 개요·N-myristoylation·prenylation
- Lipidation = 단백질에 lipid가 붙어 [[소수성|hydrophobicity|hydrophobic]]을 높여 막 위치·trafficking·상호작용·신호전달을 조절 {src:야마,PPT}
- Lipidation 4종 = N-[[myristoylation]] · [[prenylation|farnesylation]] · palmitoylation · [[GPI anchor|gpi]] (glycosylation은 lipidation이 아님) {fire:25-11} {src:vault,야마,기출}
- N-myristoylation: myristic acid([[C14|14]])가 N-말단 [[Gly|glycine|g]]에 붙음, 효소 = N-myristoyltransferase([[NMT]]) {fire:20/23} {src:vault,야마,PPT}
- prenylation: prenyl기(예 [[farnesyl|farnesylation]])가 C-말단 근처 [[Cys|cysteine|c]]의 –SH(황)에 붙음, 효소 = [[FTase|farnesyl transferase]] {fire:20} {src:vault,야마,PPT}
- (PPT, 수업에서 미설명) prenylation 후속: C-말단 [[3|세]]개 아미노산(AAX) 제거 → 남은 Cys의 carboxyl기 methylation {src:PPT,야마}
- farnesylation 예: PEX19 chaperone에 farnesyl 부착 → conformational change로 [[peroxisomal|peroxisome]] 막단백질과 더 단단히 결합 {src:PPT,야마}

#### palmitoylation·GPI anchor
- palmitoylation: palmitic acid([[C16|16]])가 [[내부|internal]] Cys의 –SH(황)에 붙음, 효소 = [[palmitoyltransferase|palmitoyl transferase]] {fire:20} {src:vault,야마,PPT}
- palmitoylation은 mutant huntingtin의 aggregation을 [[억제|inhibit|방지]]하고 polyQ 독성으로부터 세포 보호 {src:PPT,야마}
- GPI anchor = [[glycosylphosphatidylinositol|GPI|glycosyl phosphatidylinositol]] : glycolipid가 단백질 [[C-말단|C말단|C-terminal]]의 carboxyl기에 붙음 {fire:16/19} {src:vault,야마,PPT}
- 세포막 바깥쪽 표면에 단백질을 고정시키는 기가 되는 것은 GPI의 [[glycolipid|글리코리피드|당지질]] (2016-10) {fire:16-10} {src:기출}
- 정리: N-말단 Gly = myristate, C-말단 근처 Cys = [[prenyl|farnesyl]], 내부 Cys = [[palmitate|palmitoyl]], C-말단 carboxyl = GPI {src:야마,PPT}

### 10.3.3 Phosphorylation
- 인산화 효소 = [[protein kinase|kinase|키나아제]] (ATP의 phosphate를 가져옴) / 인산기를 떼는 효소 = [[phosphatase|protein phosphatase|포스파타아제]] {fire:16-12/19/20/23-14} {src:vault,야마,기출,PPT}
- 인산화되는 잔기 = [[Ser|serine]] · [[Thr|threonine]] · [[Tyr|tyrosine|y]] (side chain의 OH기) — lysine은 아님 {fire:23-14/21-9} {src:vault,야마,기출,PPT}
- protein kinase는 [[signal transduction|신호전달|신호 전달]] 경로의 핵심 / kinase 연쇄작용이 세포 표면 신호를 세포 내 표적으로 전달 {src:야마,PPT}
- epinephrine → 수용체 → adenylyl cyclase → [[cAMP]] → [[PKA|protein kinase a|cAMP-dependent protein kinase]] (cAMP-dependent protein kinase) {fire:20-12} {src:vault,야마,PPT}
- PKA가 [[phosphorylase kinase|phosphorylase]] kinase를 인산화·활성화 → 이것이 [[glycogen phosphorylase]]를 인산화·활성화 {fire:20-15} {src:야마,PPT,기출}
- 활성화된 glycogen phosphorylase가 glycogen을 [[glucose-1-phosphate|glucose 1-phosphate|G1P]]로 분해 → 혈당·근육 에너지 공급 (glycogen 합성이 아님) {src:야마,PPT,기출}

### 10.3.4 Acetylation, methylation, nitrosylation
- acetylation: acetyl기가 [[Lys|lysine|k|라이신]]에 결합 / histone에 많이 일어나 chromatin 구조·전사 조절 {src:vault,야마,PPT}
- acetyl기를 붙이는 효소 = [[KAT|lysine acetyltransferase|KATs]] (Lysine acetyltransferases) / 떼는 효소 = [[KDAC|lysine deacetylase|KDACs]] {src:야마,PPT}
- methylation: 주로 [[Lys|lysine|k]]과 Arg에 methyl기 부착, 효소 = [[methyltransferase|메틸전이효소]] / 제거 효소 = [[demethylase|demethylases]] (가역적 PTM) {src:vault,야마,PPT}
- nitrosylation: [[NO|nitric oxide|산화질소]] group이 [[Cys|cysteine|c]]의 thiol(–SH)에 결합 → S-nitrosothiol([[SNO]]) {src:vault,야마,PPT}

### 10.3.5 Ubiquitination and SUMOylation
- ubiquitin = [[76|76aa]]개 아미노산의 작은 단백질 / SUMO(Small Ubiquitin-like Modifier) = 약 [[100|100aa]]개 아미노산 {src:vault,PPT}
- 이들은 chemical group이 아니라 [[단백질|protein]] 자체를 target 단백질에 붙이는 PTM {src:야마}
- ubiquitin은 target의 [[Lys|lysine|k]] side chain의 amino기에 붙고, 이어서 더 붙어 chain을 형성 {src:vault,PPT}
- (심화) SUMOylation은 단백질의 [[위치|localization|세포 내 위치]], 안정성, 상호작용, 전사 조절에 관여 / ubiquitin은 단백질 [[분해|degradation]] 조절 단백질 (2023-13) {fire:21-8/22-8/23-13} {star:교수 강조} {src:야마,기출}
- (참고) 2017-8: 단백질이 이동할 위치를 지정하는 사건으로 출제된 정답은 [[glycosylation|glycosylation(추론형)]] (슬라이드 근거는 transportation 언급뿐) {fire:17-8} {src:기출}

## 10.4 Protein Degradation
> 다 쓴 단백질·잘못 접힌 단백질을 없애는 두 길 — UPS와 autophagy

### 10.4.1 Ubiquitin–proteasome system (UPS)
- UPS = ubiquitin이 붙은 단백질을 [[proteasome|프로테아솜]]이 분해 / 세포 단백질의 약 70–80%를 분해 (기종평 2023-10) {fire:23-기종평10} {src:야마,PPT,기출}
- E1 = ubiquitin-[[activating|activating enzyme]] enzyme (ATP로 ubiquitin 활성화) / E2 = ubiquitin-[[conjugating|conjugating enzyme]] enzyme / E3 = ubiquitin [[ligase|리가아제]] {fire:21/25} {src:vault,야마,PPT}
- 전달 순서: ubiquitin → [[E1]]에 활성화·결합 → [[E2]]로 전달 → [[E3]]가 target protein에 부착 {src:야마,PPT}
- 반복되어 [[poly|polyubiquitin|여러 개]]ubiquitin chain이 되어야 proteasome이 인식 / proteasome = 큰 protease complex {fire:16-14} {src:vault,야마,PPT}
- proteasome은 [[blender|믹서기|믹서]]와 같다 — 단백질을 선형으로 펴서 내부 protease가 잘라 냄 {fire:16} {star:교수 비유} {src:야마}
- 2016-14: proteasome = [[multisubunit|다중 subunit|multi-subunit]] protease complex로, 파괴 표지가 붙은 단백질을 분해 (vesicle·lysosome 전구체 아님) {fire:16-14} {src:기출}

### 10.4.2 Autophagy–lysosomal system
- autophagy: auto = [[self|자기]], phagy = [[eating|먹기|먹다]] (Greek) {src:PPT}
- 분해 대상 = aggregate-prone 단백질 · 병원체([[pathogen|병원균]]) · 기능 못하는 [[organelle|소기관]] (예: [[mitochondria|미토콘드리아]]) {fire:17-9} {src:vault,야마,PPT}
- lysosome = [[단일막|single membrane|1겹]]으로 싸인 소기관, 안에 protease 포함 [[acid hydrolase|가수분해효소|hydrolase]] {src:야마,PPT}
- macroautophagy 4단계: [[isolation membrane|phagophore]] 형성 → 소포 expansion → autophagosome maturation + lysosome fusion → 내용물 분해 {src:야마,PPT}
- isolation membrane(phagophore)이 기능 못하는 mitochondria를 감싼 상태 = [[autophagosome|오토파고솜]] → [[lysosome|리소좀]]과 융합 → 효소가 분해 {fire:17-9} {src:야마,PPT}
- 분해 산물은 세포 내에서 [[재사용|recycling|재활용]]됨 (교수님: 종이쓰레기 재활용 비유) {src:야마}
- 2017-9: autophagy가 일어나는 경우 = 영양 부족, [[세포 소기관|organelle|소기관]] 손상 시 {fire:17-9} {src:기출}
- autophagy 노벨상 = [[2016|2016년]]년 (일본 오스미) {src:vault}

### 10.4.3 UPS vs Autophagy 정리
- ⭐ 분해 시스템 2가지 (2025-12, 3점 단답·영어 철자) = [[Ubiquitin-Proteasome System|ubiquitin proteasome system|UPS]] / [[Autophagy-Lysosomal System|autophagy lysosomal system|autophagy-lysosome system]] {fire:25-12} {src:vault,야마,기출}
- UPS의 분해 장소 = [[proteasome|프로테아솜]] (기종평 2023-10) {fire:23-기종평10} {src:야마,기출}
- autophagy의 분해 장소 = [[lysosome|리소좀|용해소체]] (기종평 2025-8) {fire:25-기종평8} {src:야마,기출}
- 분해 대상: UPS = polyubiquitin 표지 단백질 / autophagy = aggregate · 병원체 · 손상 [[organelle|소기관]] {src:야마,PPT}
- 이 둘이 proteostasis의 output(분해)에 해당 — 약 [[1000|1,000|1천]]개 단백질이 관여 {src:야마,PPT}
